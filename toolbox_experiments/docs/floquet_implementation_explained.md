# 当前 Floquet 实现及与外部仓库的对应

本说明依据当前实际代码，不把通用矩阵求解、空间场投影和开放材料模型混为一项。
Legume 继续作为主要空间底座是合理选择；现有 Meep 对照增强了对部分静态结果的信心，
尚未提供两个结构的独立动态全波验证。两种结构动态预测都复用同一时间求解核心。

## 1. 通用时间谐波核心

入口为 `ptc_fig4/src/ptc_fig4/floquet_maxwell.py`。
物理模型提供无量纲时间 τ=Ωt 下的一阶矩阵 M(τ)：

    i dx/dτ = M(τ) x

取 x(τ)=exp(-i w τ) sum_m x_m exp(-i mτ)，其中 w=ω/Ω，
则 F_mn=M_(m-n)-m I δ_mn，解 F x=w x。
`fourier_blocks` 在一个周期等间隔采样 M，以 IFFT 取得正指数积分定义的 Fourier 系数；
`assemble_floquet` 组装 m=-N,...,N；`solve_floquet` 调 SciPy eig 求左右本征矢。
同时记录残差、谐波边缘权重、条件数并区分 Floquet 副本。该接口不负责判断输入的
M 是否完整描述实际材料、空间耦合和开放边界。

## 2. Legume 路线如何提供 M

`lpor_71318/field_projection.py` 从原生 Legume D 场与圆柱 Fourier 掩膜建立
完整保留模态之间的逆介电矩阵变化。设静态频率 W=diag(ω_j/Ω)，柱子掩膜的
Fourier 矩阵 χ=U diag(λ_q) U†，则当前实现为：

    η_q(τ) = 1/[1+(ε(τ)-1)λ_q]
    T_q,ij = a_cell ∫dz sum_components (U†D_i)_q* (U†D_j)_q
    R(τ) = I + sum_q [η_q(τ)-η_q,0] T_q
    K(τ) = W R(τ) W

主结果不加损耗时，取状态 x=(u,u')，一阶矩阵为

    M(τ) = [[0, iI], [-iK(τ), 0]]

它对应 u''+K(τ)u=0，静态时自动产生 ±ω_j 两支。
这种状态源于 D/B Maxwell 表述；并非直接令 E''+K(t)E=0 而遗漏介电时间导数。
虽然 ε(t) 只含一个正弦，其逆矩阵含高阶时间谐波和二阶平均项，程序通过实际
时间采样保留它们，不能一律只写最近邻侧带。

这是固定 Hermitian GME 模态子空间的 Maxwell 投影。它确实含保留模式间的
非对角耦合，但不等于作者 QNM 留数归一化下的完整开放展开。当前特定实现仅适配
单层圆柱，背景调制参数化为 absolute sine + optional DC + phase。
LPR 主算例最初使用 3 个同对称性模式，随后检查到 7 个。

`modal_floquet.py` 支持显式可选的固定对角 Γ：K 加 Γ²，速度块加 -2iΓ，使静态
谱为 ±W-iΓ。它是近似衰减模型，不会自动计算每个 Floquet 边带的开放通道。
已展示的结构动态主曲线未使用不可靠的极小静态线宽来推断净增益。

## 3. Meep 小实验的输入模型更简化

`toolbox_experiments/scripts/compare_meep_floquet.py` 中，Meep 给静态频率以及
同网格材料变化的频率导数，单模 S=-2(dω/dε)/ω。
`ElectricMassModel` 使用 B(τ)=I+δε(τ)S 与 K=W B(τ)^(-1) W。
Meep 两个 Science 模式是分别计算的两个单模系统；未计算它们之间的调制交叉耦合。

该模型一阶静态响应经过标定，但该一阶导数并不能唯一决定真实系统的二阶
动态响应、多模混合或辐射。它不等于 Legume 的保留多模逆介电投影。
两个路线都通过上述通用核心，因此二者动态趋势相似不是独立验证该核心的证据。

## 4. 外部 Floquet-modulation 可借鉴什么

上游 `Fmatrix.m` 将选定的 QNM 静态频率、归一化电场、辅助极化电流和积分权重
作为清楚的输入。其当前物理模型以不取共轭的 J_i·E_j 重叠生成 H±1，
再将 H0 和调制块组装为 Floquet 矩阵。可借鉴的重点是：

- 显式携带模式归一化、材料辅助场、积分权重和模式选择的数据接口。
- 对保留模式构造完整耦合块，而非仅用每个模式的自频移。
- 将材料/模式投影与通用谐波组装拆开，分别验证。
- 在适用的开放 QNM 表述中以静态复频率和正确双线性归一化处理开放模式。

它的 J/E 耦合针对色散振子调制，不能照抄成无色散背景 ε 的调制。
同样，不能把 Legume 共轭内积随意改成无共轭，或把实频率替换为复频率，
就宣称获得等价开放 QNM 理论。上游核心也不会自动补静态负频率伙伴。
这些是需要转换与验证的接口，不表示外部框架没有复用价值。

## 5. 本次新增相同输入的逐项对照

运行 `toolbox_experiments/scripts/compare_floquet_assemblers.py`，读取之前实际
MATLAB 运行原始 Fmatrix 的合成输入和输出，保持相同 H0、H+1、H-1、Ω 和截断。
上游按 N,...,-N 排列并加 mΩ；本项目按 -N,...,N 排列并减 mΩ，
对当前余弦 fixture 实际块排序一致。

10×10 算例结果：直接组装矩阵最大差 **0**；生产 IFFT+组装流程还原矩阵差
**4.44e-16**；全部本征值一一匹配最大差 **5.33e-15**；原 MATLAB 本征矢放入
本项目矩阵后的相对残差 **4.34e-16**。
记录在 `results/external_repo/assembler_comparison.json`，原始矩阵和谱也已保存。

这排查了该受控输入下组装和求解的差异，没有验证真实场到 H±1 的物理投影。
原生 Meep 均匀时变介质、解析基准和一周期积分分别提供额外验证；其中结构的
投影后一周期积分依然求的是同一个近似物理模型，不能检出双方共享的空间遗漏。

所以当前重点应放在 Floquet 扩展的物理输入：材料到底调哪一项、完整多模耦合、
场归一化、被截断模式、以及辐射通道如何进入。现有证据不支持直接认定某个
全局符号或 Fourier 组装写错，也不能以小矩阵残差证明整个开放模型无误。
