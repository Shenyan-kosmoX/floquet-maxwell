# Jin 2025 SI Figure 5：绘图与节点检查

原图与实际 Legume 场投影见 并排图（历史材料 `paper_vs_legume.png`；见[发行说明](../../../docs/RELEASE.md)）；[单独计算图](computed.png)。
图中四项依次为 Vx、Vy、Vx−Vy、Vx−iVy，没有把任何节点强制设为零。
原文色标只有 0/∞，因此本图仅比较节点的位置与消除；不声称绝对耦合标定。
轴附近亮带宽度和对角线亮度与原图不同。原文没有给出绝对色标上限，本次未拟合
该上限或材料，不能仅凭图像判定差异来自显示尺度还是物理模型。

计算图统一采用 Vref=0.00874329672，等于所有有限点上
sqrt(|Vx|²+|Vy|²) 的中位数。显示 min(Vref/|V|,100)，全部面板共用；
Γ 的单一 TE 分支未定义，按原始 NaN 显示灰色，未填补。

排除 Γ 及相邻首个网格点后，轴/对角线的最大耦合除以离轴离对角区域中位数：

| 检查 | 数值 |
|---|---:|
| Vx 在 kx=0 | 6.40685e-12 |
| Vy 在 ky=0 | 3.08665e-12 |
| Vx−Vy 在 kx=ky | 3.68339e-11 |
| 圆偏振最小耦合 / Vref | 0.565998 |
| 圆偏振最小耦合 / 同点 sqrt(|Vx|²+|Vy|²) | 1 |

圆偏振检查含 621 个离 Γ 采样点，原始计算恰为零的点数为
0。有限采样不能证明连续区域严格无零点。
本图验证周期薄膜上的张量、相对相位与模式选择规则，不是随机调制、完整
Floquet 能带、开放辐射效率或拓扑不变量的验证。模式、材料与空间收敛范围见总报告。

数据与图来源 SHA256、精确统计掩膜及尺度在 [plot_metrics.json](plot_metrics.json)。
可编辑计算图为 [SVG](computed.svg)，归一化前复耦合随 plot_data.npz 一并保留。
