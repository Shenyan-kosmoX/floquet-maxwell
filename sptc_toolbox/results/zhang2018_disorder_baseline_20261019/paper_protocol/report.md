# Zhang2018 原论文协议对照：SI Fig.1b,c

论文：[Space-time-coding digital metasurfaces](https://doi.org/10.1038/s41467-018-06802-0)，Nature Communications 9, 4334 (2018)。本结果是原论文理想反射编码模型的辅助对照，**不属于 Maxwell 或 Legume 仿真**。

原图与原码重算（历史材料 `paper_vs_protocol.png`；见[发行说明](../../../../docs/RELEASE.md)）

使用 SI Fig.1f 的全部 64 个八位序列，各位置的时序固定，八个时间槽结束后原样重复。按正文约定将 0 映射成反射系数 +1、1 映射成 -1，计算 +2 阶等效反射系数。没有随机重新生成、旋转/翻转原图、调幅或补偿相位。计算图仅从原图色条采样配色以保持呈现一致；数值全部来自原码积分，没有按色块拟合。

## 计算结果

- +2 阶幅度色块与原图逐格对应，最大幅值为 0.6366197724；显示范围与原图相同，0 至 0.8。
- 相位有未解释的约 180 度整体偏差。例如 (x=2,y=1) 直接公式为 +45 度，原图颜色约 -135 度。本图保持公式结果，不施加偏移。全局反射相位或时间原点的选择可以在数学上改变此相位，但目前没有来源证据决定原因，因此不归因于作者错误。
- +2 阶有 7 个严格零幅值格。其相位没有物理定义，显示灰色；原图为这些格赋色可能来自浮点残量或绘图选择，不能作为相位误差。
- 每槽 1024 点独立中点时间积分与闭式系数比较，m=-4…4 的最大绝对误差 1.87254e-07，+2 阶误差 6.24178e-08；从每槽 512 点到 1024 点误差降低 4.000003 倍。

## 约定与适用范围

论文使用 Γ(t)=Σ aₘ exp(+imΩt)，所以 aₘ 是乘 exp(-imΩt) 积分得到的。工具箱材料函数使用 exp(-ipΩt)，同一函数需 **p=-m**。图中的 +2 始终使用论文约定；若进一步比较散射物理频率，必须同时统一载波/场的时间约定，不能只改一个 Fourier 索引。

48/64 个位置的原编码反射平均值非零，范围 [-0.75, 0.75]。如果将这些码直接转为介电常数的正负调制，会引入空间变化的 DC 分量；若为保持周期静态参考而按格减均值，必须明确是改变后的介质驱动协议。这里保留原论文反射系数和 DC，辅助图没有假装解决这个材料映射。

本对照检验实际编码、Fourier 指数约定和时序积分。它不检验互耦、介质 Maxwell 投影、开放辐射或原金属超表面全波散射。实际 Legume 验证另行保存，不由本图代替。
