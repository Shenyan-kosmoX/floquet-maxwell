# 统一 Green 受迫响应：物理与实现审阅

2026-10-16。只读审阅核心实现，并从已有 native Legume 数据重新计算候选模态的场、辐射和局部调制重叠；未修改 Legume 或替换空间求解器。

## 这轮真正改善什么

完整 Green 观点为：给定结构、材料、调制和出射边界条件，源与远场都是同一 Maxwell 问题的映射。A/B/C/D 不是四组可独立拟合的物理参数。实际入射的振幅与相位属于输入向量；B 也随源表示、端口规范与结构固定下来。

当前 NativeSlabPortModel 的新 Green 适配可以统一多频入射，按每个入射频率使用正确的背景 B/D，并在完整 Floquet 空间中消去遗漏坐标。后者保留通过被消去模态的源、出射和跨边带直接路径，超出了单纯重新包装原单频函数的用途。

这一升级不自动补齐图案结构的连续谱、真实非共振背景或被遗漏的调制体积响应。native 数据仍是有限 GME 基底、共同频率弱辐射和均匀背景近似。即使 Schur 精确至浮点误差，绝对侧带效率也不能因此宣布改善。

## 四块消元和 Green 表示

完整谐波方程先组成 A_F x=B_F s，y=C_F x+D_F s。将状态分为 P/Q，准确消去 Q 得到

```
Aeff = APP - APQ inv(AQQ) AQP
Beff = BP  - APQ inv(AQQ) BQ
Ceff = CP  - CQ  inv(AQQ) AQP
Deff = D   + CQ  inv(AQQ) BQ
```

源、出射和直接项中的跨边带项来自同一个被消去的 Green 块，无需增加拟合参数。在完整空间内只调制内部算符、而静态 B/C/D 保持不显含时间，与消元后四块均改变并不矛盾。

对均匀薄膜体积分 Green，原始等式是 E=Ebg s+K V E，y=S0 s+Kout V E。采用 A=inv(K)、B=A Ebg、C=Kout A、D=S0-C Ebg，可得到相同的固定 B/C/D 表示：

```
y = S0 s + Kout A(E - Ebg s)
  = S0 s + Kout V E.
```

因此该实现没有遗漏直接 Born 路径。这里 D 单独不等于物理静态背景 S0，而是带有抵消项的一种状态空间实现。应同时与不求 inv(K) 的原始 Lippmann–Schwinger 方程比较，避免把逆 Green 的条件数问题误认为物理差异。

已逐式检查 `uniform_green.py`：L0=-d_z²-epsilon*omega²，G0 的导数跳变为 -1；自由空间极限为 i exp(i omega |z-z'|)/(2 omega)。V 使用输出频率 omega_l²。单位通量入射 E 为 sqrt(2)，端口 Green 相应除以 sqrt(2)。对源单元进行解析积分，包括对角 cusp 的两半积分。上述符号、频率因子和输出恒等式一致。

已检查 `green_scattering.py` 的谐波装配和 Schur 符号，未发现阻塞性错误。它在每个真实边带频率采样完整静态映射，并先装配 A_F 再消元；静态各块 A 不必分别可逆。独立均匀薄膜测试属于 Maxwell 参考，不代表实际二维图案的绝对散射准确度。

## BIC 与奇异性必须保留的区别

1. 静态某个 A(omega_l) 可在暗态处奇异，但调制耦合可能使完整 A_F 可逆。应直接求完整矩阵，不能先强迫每个静态 G0 存在。
2. 若完整算符有不可激发、不可观测的零空间，外部 S 可以唯一而内部状态不唯一。可选的 compatible-observable 解只选择一种内部代表，不应报告为唯一稳态场。
3. 消去的 AQQ 可奇异而完整 A_F 可逆。此时改变分区、保留相关态，比给 AQQ 任意伪逆更合适。
4. 可解的受迫代数方程不证明泵浦系统稳定。必须沿用独立增长率／周期映射证据，才可以将其解释为长期连续波效率。
5. 原生静态 BIC 的辐射趋零不意味着所有调制边带都不辐射，也不意味着入射波能够激发该态。

## 归因与下一步的边界

- 旧接口对多个输入谐波冻结同一载频背景属于接口／实现错误风险，本轮一致采样消除了这一风险。
- 只补自能却丢失被消去坐标的输入与输出路径，是表示缺项；加密频率不能补回这些路径。
- 固定表示下 Green 网格或谐波变化，属于数值收敛，应通过同一物理模型的加密判断。
- native 与独立全波绝对效率仍不同，可能同时受静态背景、源留数、连续谱、辐射冻结和参考空间离散影响。当前恒等式验证不能单独判定其原因。
