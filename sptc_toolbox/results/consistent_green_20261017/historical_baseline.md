# 历史 14%–17% 比较的复测契约

这里记录本轮实施前锁定的历史算例、数据来源及新版复测条件。后续已完成[当前原生路线重算](native_retest/summary.json)及[新r32标量弱转换对齐](analysis_r32/report.md)，新旧离散表示的差异仍保留。以下“等待复测”描述保留为实施前的状态，不是本轮最终状态。**14%–17% 是历史近似模型与历史 r32 参考之间的差异，当前状态是等待新版同条件复测；它不是最新 pipeline 已确认的误差，也不能用新版 r24 混合模型的复振幅差替代。** 本文件未运行新的 Maxwell 仿真，未改动旧数据。

## 原始比较确实是什么

| 观测量 | −1 侧带，fa/c = 0.388 | +1 侧带，fa/c = 0.408 |
|---|---:|---:|
| 旧 Legume 原生端口模型的总出射功率／入射功率 | 0.0001317392578255223 | 0.0001359786533442951 |
| 旧 Meep r32，t = 900 的一级极化电流参考 | 0.00011220728109203111 | 0.00011877672025167711 |
| 旧模型／旧参考 − 1 | +17.4070493% | +14.4825796% |

功率对上下两个空气零阶 x 偏振端口求和。旧模型输入为底侧单独入射 `(1, 0)`，不是同相或反相双侧。正入射频率及这两个正侧带不存在正负频率重合的相干功率问题。

模型数值来自 [connected_physics/ports/summary.json](../connected_physics/ports/summary.json) 中幅度 0.01 的 `dynamic` 项，由 [validate_slab_ports.py](../../scripts/validate_slab_ports.py) 生成；对应完整幅度保存在 [modal_dynamic.npz](../connected_physics/ports/modal_dynamic.npz)。参考来自 [weak_pattern_r32_t900/summary.json](../targeted_resolution/ports/weak_pattern_r32_t900/summary.json)，由 [meep_weak_sideband.py](../../scripts/meep_weak_sideband.py) 生成；[summarize_targeted_ports.py](../../scripts/summarize_targeted_ports.py) 只读取两者并计算比值，没有求解或拟合。

## 必须保持的物理契约

| 项目 | 固定值与约定 |
|---|---|
| 晶格与 Bloch 点 | 二维正方晶格，周期 a = 1；Γ，即 k = (0, 0) |
| 薄膜 | 厚 0.42a，背景相对介电常数 11.5；无材料吸收、无色散；上下空气 ε = 1 |
| 两个空气孔 | 圆孔中心 (−0.22a, 0)，半径 0.12a；椭圆孔中心 (+0.22a, 0)，半轴 (0.12a, 0.09a)，贯穿薄膜 |
| 坐标平移 | Legume 层 z ∈ [0, 0.42a]；Meep 薄膜 z ∈ [−0.21a, +0.21a]，场导出须作此平移 |
| 载频／驱动 | f₀a/c = 0.398，fΩa/c = 0.01；内部角频率 ωa/c = 2πfa/c |
| 调制 | 高介电薄膜背景排除两个孔，δε(t) = 0.01 cos(Ωt)；绝对 ε 幅度，不是相对调制深度；Fourier δε±1 = 0.005 |
| 外部入射 | 底侧、x 偏振、法向入射；同一参考平面的单位入射功率 |
| 端口参考面 | 薄膜中面坐标 z = ±0.7a；空气中相同面积 a²；零阶远场复振幅和总侧带功率 |
| 时谐约定 | exp(−iωt)；极化电流 J_l = −iω_l δε_l E_carrier |

这些是本地通用二维薄膜验证算例，不是两篇历史论文的任一图；不得给本算例贴上论文图复现标签。

## 历史两条数值路线

旧 Legume 端口模型：实际 native.pkl 的 Γ 模式 5，fa/c = 0.3979539246410964；gmax = 6.1，导模族 0…7，custom 参考 ε = 10，导出 16 个本征模，但动态端口模型仅保留模式 5。投影区域为 dielectric background，z_order = 16。辐射通道在该模式频率处采样并冻结。非共振直接路径采用几何面积平均均匀薄膜 ε = 10.668734583860141，厚度 0.42，界面到端口距离 0.49；它不是完整图案背景。动态求解 n_harmonics = 3、n_samples = 96，另有 4/128 对照。旧内部 ODE、功平衡、谐波截断检查验证的是该近似模型本身，不能证明它的真实图案散射留数完备。

旧 Meep 参考：r32、cell = (1, 1, 4.8)、z 向 PML 厚 0.65，内缘 |z| = 1.75，`eps_averaging=True`，未使用原生 Mirror 边界。底侧平面电流源在 z = −1.2，`ContinuousSource(width=20)`。空单胞推进到 t = 150，载频及每个侧带响应推进到 t = 900，并同步 H 后读出。载频中心采样体积为 (1, 1, 0.5)，取 Ex/Ey/Ez 后插值到极化电流源的 Yee 位置，再在该位置应用锐物理掩膜；源体积为 (1, 1, 0.42)。这是一级 Born 对照，没有载频耗尽或重复转换。

旧 `carrier.npz` 的 Ex/Ey/Ez 是未经入射归一化的原始复场。`incident` 是独立空单胞底端口前向电场幅度，使用 `E_raw / incident` 才得到单位入射切向 E 场；面积 1 的空气中，其入射功率为 1/2。端口分解为 `(Ex ± Hy)/2`，输出／incident 的幅度平方求和直接给功率比。若转换到工具箱单位入射功率的字段，需用 `sqrt(2)*E_raw/incident`。新版静态数据已经归一化的场不能再次除 incident。

## CW 返回值问题不影响这份历史参考

历史 r32 JSON 明确记录 `static_green_solver="time"`、`settling_time=900`。脚本 `solve()` 的 time 分支调用 `sim.run()`，最后直接返回 `True`；只有 cw 分支调用 `sim.solve_cw()`。因此旧输出中的 `empty_cw_return`、`carrier_cw_return` 和 `solve_cw_return` 是被两条分支复用的误导性字段名，**不是使用 solve_cw 的证据**。本轮发现的 CW 返回值兼容性问题不能追溯为这些 FDTD 数据的失效原因。JSON 与脚本的 SHA256 已与当时 validation_manifest 核对一致。

默认连续源的 dipole→电流时间差分因素仍适用于旧时间推进侧带源。它和 CW 返回值是不同问题：前者影响源规范，后者只影响新频域运行的状态判读。应在新版中统一规范，保留旧数值原样，不将其解释为已定位的 14%–17% 主因。

## 新版最小端到端复测

1. 保持上表物理模型、固定载频、底侧单独入射和功率观测量。不平移极点、重标幅度或修改材料以追逐旧曲线。
2. 统一一个离散静态算符内的源提升、原生场测试／Gram、材料扰动和出射提取。若改用原生镜像或材料离散设置，将其记为新数值算符；不得混用旧无镜像模板、旧 E0 与新 Green 数据。
3. 在 r32 至少获得载频完整入射场、f = 0.388/0.408 所需模板响应，以及同一离散本构扰动产生的完整一级电流参考。单侧入射需包含真实偶／奇两个扇区并相干组合，不能只复测偶模板。
4. 先比较同一个离散 Maxwell 问题内完整一级电流与投影一级结果，分别报告上下端口复振幅误差及两侧总功率差。再报告有限谐波动态反馈相对 Born 的变化；不同阶近似不得混为一个误差指标。
5. 若目的是回答历史差异是否消失，表格必须同时保留“旧 native”“旧 r32 FDTD”“新 native 路线”“新版混合路线”“新版完整参考”中实际可得到的列，并明确缺失列。新的混合路线可以改进物理参考，但不会自动验证旧单模原生端口闭合。
6. 判定采用当前观测量尺度：端口功率／复振幅的精度、载频失谐和稳定求解。三个实频的弱转换对照不承担完整边带收敛或强泵稳定性的证明。

可直接复用：原物理几何、固定调制、原 Legume 空间缓存（字段重新采样到新网格仍可复用 native 解）、旧预测与原始参考作为历史列、旧时间/PML诊断作为计算选择依据。

必须重算或重新投影：新版一致源／场度量下的材料矩阵、对应新离散算符的模板响应及入射场、同一离散扰动的完整一级电流参考、动态组装与端口功率。旧 r24 混合结果不能填入 r32 新版列。已完成的 r32 t = 1800 载频与 PML 控制仅验证未改镜像／材料离散的旧算符；它没有重算历史侧带。

已有独立参考控制显示，r32 的 t = 900→1800 内部场变化约 1.395%，复 S 变化约 1.857%；t = 1500→1800 则降至约 0.055%／0.072%。PML 0.65→0.9、内缘固定后的场差约 0.000206%。这支持采用更直接的稳态求解，但不是把历史侧带功率修正为某个新数值的依据。
