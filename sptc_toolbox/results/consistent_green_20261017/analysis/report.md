# 同一离散 Maxwell 模型中的受迫 Floquet 闭环

本轮使用实际 Legume 场作为第一源方向，用新静态偶／奇背景增广，并由 Meep 独立计算每个原生极化源的静态响应。所有混合动态输入均来自新 `eps_averaging=False`、r24 的同一离散材料算子。**这是混合验证，不是纯 Legume 完整散射。原历史模型也已用当前 NativeGreen 实际重算，其单模、冻结辐射和均匀背景近似仍保留。**

静态场、源提升、材料导数、体积度量和离散出射通道已经统一。未用目标侧带结果选择振幅、相位或材料；未对响应矩阵对称化或正定化。

## 材料直接重算与完整极化源控制

实际 ε±0.01 中心差分相对独立单位极化源的复输出差为 **0.031007%**，内部场差为 **0.042989%**。中心差分有二阶扰动余项；这不是一项可自动外推为零的误差。

侧带比较双方均使用绝对介电调制 cos 振幅0.01，即每个 ±1 Fourier 系数0.005。完整源参考使用未经模态投影的载频场；采样文件的单位 δε 响应只乘0.005一次。若参考通过真实完整偶／奇极化源分别求解再相干组合，JSON明确记录子计算及组合身份；该组合不是由有限模板响应代替完整源，也不宣称额外完成一次全域求解。DC比较是实际重建材料后的总散射，不是同一 Green 公式的自检。
