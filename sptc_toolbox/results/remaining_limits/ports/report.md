# 实际二维结构的物理端口与静态散射尝试

Meep只作为独立物理散射参考，Legume仍为模态空间底座。对同一圆孔／椭圆孔薄膜，以空单胞校准入射平面波，提取底／顶端口复振幅。保留反射、透射的相位和通量，背景不预设为−I。

| 控制 | 最大误差 |
|---|---:|
| 均匀薄膜 uniform_r16 对独立Fresnel复振幅 | 0.062879 |
| 均匀薄膜 uniform_r24 对独立Fresnel复振幅 | 0.023902 |
| 均匀薄膜 uniform_r32 对独立Fresnel复振幅 | 0.013195 |
| pattern_r24_t300 的最大 |R+T−1| | 0.12435 |
| pattern_r24_t900 的最大 |R+T−1| | 0.0063309 |
| pattern_r32_t300 的最大 |R+T−1| | 0.1516 |
| pattern_r32_t900 的最大 |R+T−1| | 0.0068522 |

复杂S在r32记录时间300→900的最大变化为0.079099，时间900下r24→32最大变化为0.08236，共振附近误差仍显著。
尝试以固定原生Legume复极点加平滑余项拟合复S，交错频点留出误差131.68%。没有移动极点强行对齐，也没有将这组残差系数转换为已认证的动态耦合。
新增StaticPortReference保存物理参考面和flux-amplitude规范，能计算静态输入／输出功率，并明确它是total S而非direct background。
**本项完成的是实际静态物理端口和可检查参考，不是Legume-Floquet的动态R/T／转换效率接入。**要进一步接入，需要在同一模态场规范下辨识输入耦合、输出留数和非重复计数背景；不能把测得total S直接叠加到原有模态项。
