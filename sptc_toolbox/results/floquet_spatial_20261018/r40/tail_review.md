# r40 静态尾部处理与完整 Floquet 核验

本次完成真实 r40 网格、17 个源坐标、五个实际频率的全部 95 个静态响应。每个源保留 500、1000、1500、2000 四个累计 DFT 时间窗。完整原始窗口 Floquet 解位于 `analysis_raw/`，经本报告范围内选样的解位于 `analysis/`；没有改写原始数据，没有复用 r32 极点，也没有把 CW 失败或缺失写成通过。

## 为什么采用统一偶扇区尾部完成

偶入射响应本身的真实五频增量给出两极点
`0.38924062310986646 − i 4.054988023058927e−6`、
`0.3975762489295289 − i 7.99337601064276e−4`（单位 fa/c）。
频率离散定律、极点衰减和独立后续增量检查都满足预先声明的尾部模型检查。

对整个偶扇区使用相同线性时间算子。E、D、输出、入射、原生端口场同步处理；入射数据先恢复各窗原始 DFT，再按修正后的入射端口归一化。所有候选始终保留在 `tail_diagnostics/rank2/`，正式使用与否由 `sampling_selection.json` 单独记录。

`template_q6`、`template_q8`、`extended_q13`、`extended_q15` 自己识别两极点的模型检查未通过。这个历史失败没有被删除或改判。固定使用偶入射识别的两极点之后，仅以前两段增量确定每个源的残量，预测独立第四窗：十个偶源的 E/D 增量相对残差最大 `2.4565e−4`，输出增量最大 `6.7832e−4`，均小于原有 `1e−3` 模型判据。部分模板入射泄漏增量的相对误差较大，但其绝对功率很弱，所有值完整保留。

两个错开三窗 `[500,1000,1500]`、`[1000,1500,2000]` 的共同极点外推，其偶源输出最大相对差为 q6 的 `9.24e−5`。这两组窗口互相重叠，不能称作互不重叠的独立实验；第四增量预测提供额外未参与残量拟合的时间检查。

九个奇源不使用拟合候选，保留原始 t2000。其最后一段累计输出变化最大 `1.487e−5`，内部 E 变化最大 `5.40e−4`。没有由此宣称所有弱内部模或 QNM 极点已认证。

## 方程、材料与功率

独立离散平面波在实际 40×40×32 原生坐标上检验 curl-curl 的符号与交错网格索引，误差分别为 `4.39e−14`、`1.27e−14`。对选用的全部 95 响应，内域（剔除两层 z 边缘）结果为：

| 检查 | 最大测量残差 |
|---|---:|
| `E−K D` 相对 E | 2.20e−14 |
| `curlcurl E−κ²(D+Q)` 相对算子项范数和 | 5.68e−5 |
| 同一 Maxwell 残差相对实际源 | 8.53e−4 |
| 单独模板端口功绝对缺口 | 7.66e−5 |

这是实际测得的敏感性，没有事后设定一个 Maxwell 门槛将其改判通过。内域检查不能替代 PML 或完整开放边界收敛。

弱源相对功异常仍存在。例如 q8、f=.378 的输出功率 `8.43e−6`、功缺口 `4.92e−7`，相对为 **5.84%**；ext11、f=.398 输出约 `2.27e−9`、功缺口 `−1.05e−10`，相对约 **−4.40%**。不能用一个大信号相对范数掩盖这些弱通道。q6、f=.388 的绝对功缺口达到 `−7.66e−5`。完整逐源/逐频绝对值和相对值见 `tail_validation.json`。

q8 的已声明源支撑舍入遗漏为 `1.25394e−11`，小于采样时已声明且经首步审计的 `1e−10` 注入容差。诊断读取这项实际采样声明，按真正注入的受支撑 Q 计算 Maxwell 残差，并单独记录遗漏。源列本身和其哈希保持原样。首次诊断旧硬编码阈值拒绝的记录保留在 `maxwell_q8_preliminary/`；修正诊断约定后的记录在 `maxwell_q8_source_audited/`。

## 对实际有限 Floquet 结果的影响

单位 bottom-x 载频入射、总输出端口功率如下：

| m | 功率/单位入射功率 |
|---|---:|
| −2 | 1.6742475118e−9 |
| −1 | 1.09331110231e−4 |
| 0 | 0.9997826596346 |
| +1 | 1.07860877869e−4 |
| +2 | 1.94644175370e−9 |

原始 t2000 与选样后的一级复振幅差为 **0.01575% / 0.01425%**，完整 S 相对差 `4.119e−5`。与同 r40 的独立完整极化电流 Born 参考比较，一级复振幅差为 **0.03357% / 0.03396%**；该参考只用于弱调制辅助控制，未用于拟合响应。

M1→M2 一级复振幅变化为 **0.003205% / 0.003492%**。rank13→17 一级复振幅变化约 `7.5e−7`，二级为 `2.10e−4 / 8.83e−5`。最终全输入源表示残差最大 `4.304e−4`；载频输入为 `5.102e−5`。源表示残差不是散射误差上界。

剔除旧 q6–q8 的附加控制仅使载频一级复输出变化 `6.26e−6 / 2.70e−6`，二级约 `4.88e−4 / 5.08e−4`；但是这套缩减基底未满足原先的全五频源覆盖要求，因此只作敏感性诊断，没有替换 rank17。

表示出来的动态极化源做功与出入射功平衡缺口最大 `7.25e−8`（单位入射功率）；加权转换互易残差 `2.494e−6`。零调制恢复误差 0，相位原点协变误差 `1.69e−16`，离线重载重算载频误差 0。

这些结果支持把同一偶扇区尾部完成用于**本次有限五频、弱调制、受迫散射**。它不认证所有单独模板的弱通道、高 Q 复极点、动态阈值、完整 QNM 或所有波矢；也不能抵消 r32→r40 之间真实空间敏感性。新 r40 数据没有独立 CW 对照，正式元数据明确为 `continuous_wave_solver_validated=false`。

## 可追溯文件

- `sampling_selection.json`：仅选择十个偶源；九个奇源按默认使用 raw t2000。
- `tail_validation.json`：完整 95 响应、失败模型、弱源功异常、来源哈希和范围。
- `tail_diagnostics/summary.json`：所有源真实窗口和极点诊断。
- `maxwell_diagnostics/summary.json`：原始＋候选方程和端口检查。
- `analysis/summary.json`、`analysis/report.md`：完整所选 Floquet 控制。
- `analysis_raw/summary.json`：保留原始有限窗的完整计算。
- `analysis/validation/manifest.json`：随数据携带的原验证文件和哈希。
