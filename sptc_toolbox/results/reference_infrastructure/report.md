# 通用空间接口的解析正例

2026-10-14实际运行 `scripts/validate_reference_infrastructure.py`，结果为
`PASSED_ANALYTIC_SLAB_CONTROL`。此例为无图案均匀薄膜，物理介电常数12、厚度0.4a、
上下空气；它与两篇论文均无参数继承关系。

在 `ka=(1,0.3), (1.02,0.3), (1.04,0.3)` 上，用空气边界条件独立求解TE0色散：

`q tan(q d/2) = alpha`，`q²=12 Omega²−k²`，`alpha²=k²−Omega²`，
`Omega=omega*a/c`。选定区间内没有tan极点，原生Legume结果以`f*a/c=Omega/(2pi)`比较。

粗基底为gmax=2.1、导模族(0)、输出5模；细基底为gmax=3.1、导模族(0,1,2,3)、
输出8模。比较使用两次实际原生空间求解，其物理结构精确哈希一致；细基底目标由
粗基底TE0物理场匹配。场在G并集内补零，z窗延至薄膜两侧各12a，并按多个区间求积。

`frequencies.npz`与`summary.json`。
