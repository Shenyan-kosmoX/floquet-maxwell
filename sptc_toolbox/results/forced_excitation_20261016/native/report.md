# 实际 Legume 薄膜的相干受迫激励

沿用已保存的 gmax=6.1、8 个垂直导模族的原生 Legume 结果，重新从 mode 5 的场计算背景介质区域投影。载频 fa/c=.398、调制频率 .01、介电常数余弦幅度 .01；没有使用拟合的共振频率或耦合系数。

相干源选择（历史材料 `native_source_selection.png`；见[发行说明](../../../../docs/RELEASE.md)）

- 入射总功率均为 1。symmetric 双侧源使内部坐标权重达到单侧源的 **2 倍**；antisymmetric 源不激发该对称性的选定模态，直接散射仍存在。
- 源相位扫描与该模式端口对称性推导的 1±cos(phi) 权重相差 **4.46e-13**。这是相干输入接口的物理一致性检查，不是新的独立空间收敛结果。
- 单侧源的 −1/+1 边带功率为 **0.000131739258 / 0.000135978653**。对应亮源分别为 **0.000263478516 / 0.000271957307**。
- 独立单周期评估给出 **stable**，最大增长率为 **-0.0751003073 /tau**。输出功率因此可解释为这个有限模型的吸引稳态。
- 时间谐波 N=3→4 的最大目标边带功率绝对变化 **1.32e-14**。

这些结果说明现在可以明确指定“从哪边、以什么相对相位照射”，并得到源相关模态激发和侧带输出。仍采用冻结辐射和几何平均均匀背景；本轮没有修正其此前记录的绝对散射效率误差。内部 q/v 权重只是同一坐标规范下的比较量，不标记为光子数。
