# Science追踪失配的局部原因：谱窗与参考导模截止

日期：2026-10-14。**本轮已取得比“不闭合”更具体的原因证据：有限输出谱窗遗漏部分场分量，但增加28→80模仍不能恢复连续；主要失败边同时跨过参考均匀薄膜的导模截止，参与目标场的导模基底行实际消失或出现。原z积分精度不是主要原因。** 这是所选GME参考基底的限制证据，不能据此称Legume有bug，也不能用来宣称物理结构发生拓扑braiding。

## 严格控制的计算范围

只计算30点已保存路径的索引18、19、20、24、25，共5点。未改原基线、追踪模块或旧缓存。物理ε=16、reference ε=16、gmax=5.1、导模索引上限24、xy-even、无kz分块均固定。唯一空间求解改动是输出本征模数量28→80；Legume的`eigh`本来就对该k的全部Hermitian矩阵对角化，再取`numeig`个最接近eig_sigma的模态，因此这是输出窗口扩展，不是增加空间基底。

原有28模在新输出中按同k物理H场一一匹配；不是按频率追踪跨k。全部28模重现到最大频率差约1.4×10^-12 THz、最差同模重叠误差约1.1×10^-15。说明本轮比较确实保持了原空间问题；新窗口大致覆盖32.5–132.2 THz。

在同一新缓存上进行两次H场重构：原积分（每区域8节点、空气尾部各1a）及细积分（每区域32节点，分割[-4,-1]、[-1,0]、[0,h]、[h,h+1]、[h+1,h+4]）。细积分既可只取原±1a域，也可加入至±4a的尾部；由此分开检查节点精度与截断尾部。没有再运行第二个材料/基底配置。

运行入口：`scripts/diagnose_spatial_window.py`。完整新缓存、所有80模H场、guided标签、投影和频率位于 `results/spatial_window/`。首次原生求解约5.6秒，含场重构/存档的诊断约165秒。`--report-only`仅读取已存结果生成说明与图，不重算Legume。

## 参考导模截止的独立解释

同一reciprocal G集合并不保证同一个guided-mode Hilbert空间。Legume按每个`G+k`实际可用的参考薄膜导模组装基底：`gmode_include`列出导模阶次，`ind_modes`再列出该阶次存在的G行。读取这些数组只作版本1.0.3的诊断；没有修改库或重写其求解。

对于对称εref=16、空气ε=1、厚h/a=0.44452347的参考均匀薄膜，第p阶TE/TM导模的截止横向波数为

`g_cut = pπ / [(h/a) sqrt(εref−1)]`。

原生index4对应TE的p=2，`g_cut=3.649551884`；index7对应TM的p=3，`g_cut=5.474327826`。这是参考波导的光线截止，不是实际柱阵空气衍射阶的Rayleigh阈值。

### 边18→19：有显著权重的TE2基底行消失

k从(2.580593965,0)到(2.692793703,0)。在G=(-2π,0)上，`|G+k|`从3.702591342降到3.590391604，穿过TE2截止3.649551884。该index4/G行因此消失。两个源目标模式（62.7640和68.6297 THz）在这条丢失导模系数行上的权重分别为 **22.2587%和1.5343%**。

与此同时，较高阶index12与19各增加两行；但接收目标两态在这些新增高阶行上的权重仅约5.2×10^-10和1.1×10^-7。这解释了为什么总维数932→935甚至增加，却不代表旧目标场的相关方向还在。到80模窗口仍不能恢复丢失导模连续空间，和上述实际投影保真一致。

### 边24→25：总维数不变，低阶TE2与TM3的可用行交换

k从(π,1.795195802)到(π,1.907395540)。两个index7/TM3行的`|G+k|`从5.478289350降到5.386756027，穿过TM3截止5.474327826，因此消失；它们在源两个目标态上的权重只有约1.3×10^-5和1.1×10^-5。

但两个index4/TE2行出现：G=(-2π,0)和G=(0,0)上的`|G+k|`从3.618332816升到3.675290757，越过TE2截止。两个接收目标态（66.5589、68.5092 THz）在这些新增行上的系数权重为 **4.0564%和9.2271%**。总维数同为932，因此只检查矩阵维数会漏掉这个实际的空间基底变化。新增TE2成分在反向的旧基底中不存在，与25→24投影差而24→25良好一致。

这些系数平方是原生正交guided基底中的贡献指标；不把它直接等同于整个物理场的损失比例，也不当作开放QNM范数。它们与解析截止位置、方向性投影和长尾结果共同构成原因证据。

## 新增80模不是一条“漏掉的正确近频带”

在18→19方向，新增窗口中较大投影来自约110.008、112.252、105.730 THz的模态，单模对源二维平面的投影约0.0520、0.0242、0.0186；它们与目标60–70 THz区间明显不同。其H场在patterned layer内的范数占比约93–97%，三个笛卡尔分量权重也已保存。25→24方向较大新增投影来自116.552、107.118、99.559 THz，投影约0.0300、0.0151、0.0096。

这说明扩窗恢复的是分布在多条模式上的场成分，而不是找到一个应直接替换当前两模标签的隐藏近频模式。所有相关频率、投影和`H_cartesian_norm_fractions`在summary中逐项记录；这里的层内H范数不是ε加权电能局域化量，不拿它验证FW qBIC。

原selected模式的8→32节点范数相对变化约10^-5–8×10^-5；长尾新增占比在点18第一目标约4.11%、点25两个目标约1.10%和2.42%，其他selected模式通常更小。这些尾部变化能改变几个百分点的投影，却不能恢复到完整连续两带。

## 结论和下一步的受控边界

现在可排除“只是旧z积分节点不足”作为主要解释。旧28模窗口确实遗漏部分成分，但80模仍不充分；两个最坏边恰好穿过参考导模截止，且有显著目标权重的行进入或退出。这是当前custom-reference GME离散子空间变化的具体问题，不能仅通过更聪明的标签追踪或增加numeig解决。

下一轮应在**Legume底座内**固定物理圆柱，只对reference ε、导模阶次选择/截止稳定性和更完整的参考子空间做少量受控比较，要求目标物理H场在跨k基底间高保真，并同时报告实际guided行集合。修改参考基底是数值设置，不是调材料去拟合论文。若仍缺辐射连续谱，应继续明示GME适用边界，而不是宣称库bug或强制闭合。

本轮没有重新追踪/接受80模全路径，没有计算新Floquet能带，没有改原缓存，亦没有用新高频态替换目标来制造闭合。两条Science母模跨BZ的身份依然未通过，但失配来源已从单纯现象推进到可复核的谱窗与参考基底截止证据。
