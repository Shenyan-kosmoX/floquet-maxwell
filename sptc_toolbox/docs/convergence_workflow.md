# 分层收敛工作流

`sptc_toolbox.convergence` 比较固定物理模型的数值加密。它不运行 Legume，
不自动确认模态身份，也不根据两张相似的图认证求解器。实际运行脚本负责
空间求解、场匹配、材料和辐射适用性检查，再把证据交给此模块。

建议分开检查 `spatial`（平面波和导模）、`modal`（保留的静态带/动量扇区）、
`temporal`（积分步长或时间边带）及 `sampling`（Bloch 网格等）。最后可增加
`joint` 对角检查，但不能用它归因于某个单独截断。

## 以物理问题决定检查范围

本工具服务于物理机制仿真。数值精度要求来自当前要回答的问题；统一的绝对频率阈值、
完整QNM框架或全BZ身份认证不应成为所有基线的前置任务。
先明确目标现象和观测量，再判断加密／近似变化是否足以改变物理结论。
观测量及重要尺度应在评价结果前明确，不能事后只选择恰好稳定的指标。

| 当前问题 | 优先检查的物理量与尺度 |
|---|---|
| 调制打开带隙、共振杂化 | 带隙／劈裂及参与模态，和失谐、耦合、线宽相比较；无调制及相关参数对照 |
| 放大与衰减 | 增长率的符号和大小、无泵浦被动控制，以及独立时间演化；接近零的符号必须有足够分辨力 |
| 波包拖曳、展宽、输运 | 实际中心、宽度、场分布与目标传播时间；微小频率差可能随时间积累，不能只看频率相对误差 |
| 辐射干涉、BIC或EP | 相关模态／子空间、共同辐射通道及相应可观测行为；只看到相近实频不够 |

整体频率平移不自动否定带隙形状或某个机制，但在固定驱动频率下可能改变失谐，长时间传播
也可能受影响。若需要另做调整驱动后的比较，须单独声明物理参数变化，不能混入同一收敛序列。
具体而言，相同频移可在模间差频共振中抵消，却在参量和频共振中累加；也可能改变边带与
衍射阈值的相对位置。因此绝对频移是否重要应由实际共振条件判断。
小残差、高场重叠、谱线形状相似都不能单独决定物理是否正确；它们应与目标观测量、
限制情形及适用的独立参考共同判断。

`NOT_CONVERGED` 只表示供给的量没有达到该次声明的数值标准，并不等价于“机制错误”或
“工具箱不可用”。`PASS_SEQUENCE` 保留原来的严格语义；探索性物理结论不必都等到它通过。
报告应分别说明：机制得到哪些证据支持、定量结果有多大敏感性、采用什么近似。
若目标机制在相关加密与控制中保持、现有敏感性不足以推翻该结论，就可以继续研究和复现，
同时给出适用范围。若模式身份、带隙开闭、增益符号或其他核心结论会改变，则优先解决它。

本轮空间绝对频率1e-5、模态频率1e-7等标准是专项精度检查，不是所有SPTC问题的通用
准入条件。历史结果和数值状态原样保留；后续按物理目标另设标准并记录理由，不以已有
差异为依据调整阈值凑通过。严格QNM／阈值自能等开发由实际基线暴露的影响驱动。
符号、单位、Maxwell质量映射、重复计损耗及非物理增长等实现错误仍应修复。

## 快照与容差

### 先归因，再选择加密或理论补全

2026-10-16方法原则：先抽象底层逻辑，再查前人处理方法。对一个异常结果先区分以下假设，允许多种误差同时存在：

| 假设 | 能区分它的检查 | 后续动作 |
|---|---|---|
| 固定物理模型的数值误差 | 一次改变一个离散化参数；保持几何、材料、源、泵和场身份；观察与目标物理尺度相关的量 | 加密主导误差轴，记录相邻变化；无已知阶数不强做Richardson外推 |
| 实现／接口错误 | 单位与符号、独立原始方程、解析极限、规范变换、相干性或守恒反例 | 修复具体映射或算法；不能通过放宽容差或改物理参数消除 |
| 模型表示不完整 | 固定离散化已稳定，但缺少源驱动、输出留数、背景、连续谱或正确出射分支；比较不同有物理定义的表示 | 写出算符／投影／边界问题，核对已有文献方法与所需输入，再实现最小必要补全 |
| 物理输入或文献对应不确定 | 论文目标模、材料、调制定义、边界与我们的模型未唯一对应 | 查主文/SI/代码和材料来源；保留明确假设，不将其误认成收敛错误或作者错误 |

例如受迫散射需要共同定义的 A、B、C、D：A x=B s_in，s_out=C x+D s_in。
本征谱和自由衰减主要检查A；即使A计算到高精度，也不能自动确定B、C、D。
消去外部/遗漏自由度时，四项一般同时改变，只补自能或输出通道不保证散射一致。
该问题的文献映射与精确有限模型反例见受迫散射底层审计（历史材料 `../literature/scattering_foundations_20261016/README.md`；见[发行说明](../../docs/RELEASE.md)）。

收敛曲线变平只表示所检参数下的变化变小；若剩余物理量依赖未检查的模态、谱尾、PML或场规范，不能由平台期直接诊断“理论错”。反过来，缺少整个通道、背景项或相干交叉项时，继续增加时间谐波也不会把它补出来。

`Snapshot` 包含以下字段。数组和映射会复制并设为只读，`as_dict()` 可保存为 JSON。

| 字段 | 内容 |
|---|---|
| `physical_signature` | 几何、物理材料、驱动及实际 Bloch 点等；必须保持不变 |
| `model_scope` | 投影表示、损耗归属和辐射近似等；必须保持不变 |
| `numerical_controls` | 所有数值截止、网格、积分/采样阶数；每次声明实际改变的键 |
| `observables` | 带单位的 `Observable` 标量或数组；数组须已在相同物理坐标/身份下对齐 |
| `limitations` | **阻断式表示限制**，见下文；默认空元组 |
| `metadata` | 来源哈希、路径、已知范围、辅助诊断和非阻断备注 |

不要把物理参数调整当作收敛；换辐射模型也不是同一模型的数值加密。
多个控制同时改变须显式 `layer="joint", allow_joint=True`。
`declared_axes` 必须与实际变化的控制键完全一致。

逐元素容差为 `atol + rtol * reference_scale`。`rtol > 0` 时必须提供尺度；
尺度可为标量或与观测量兼容的数组，并允许显式为零。计算不除以接近零的
观测值。尺度应来自目标带宽、线宽、间隙或观测时间，而非为了使当前差异通过。
单位必须一致；例如角频率与普通频率的 `2π` 不由本模块推断。

下面是 API 演示，数值不是本项目的物理结果。身份尚未验证，因此结果是
`UNASSESSED`，即使数字很接近也不会自动通过。

```python
import json
from sptc_toolbox.convergence import (
    Snapshot, Observable, Tolerance, PairEvidence, compare_sequence,
)

physical = {"geometry": {"r_over_a": 0.25, "d_over_a": 0.55},
            "epsilon": 12.1, "modulation_depth": 0.02}
scope = {"projection": "electric_mass", "radiation": "verified_guided_only"}
levels = [
    Snapshot(
        run_id=f"g{g}", physical_signature=physical, model_scope=scope,
        numerical_controls={"gmax": g, "gmode_inds": [0, 3], "steps": 2048},
        observables={"gap": Observable(gap, units="angular c/a")},
        metadata={"scope_note": "Finite guided model; not an outgoing QNM certification"},
    )
    for g, gap in [(3.1, 0.001), (4.1, 0.001004), (5.1, 0.001005)]
]
report = compare_sequence(
    levels, declared_axes=["gmax"], layer="spatial",
    tolerances={"gap": Tolerance(atol=1e-6, rtol=0.01, reference_scale=0.001)},
    evidence=[PairEvidence(), PairEvidence()],
)
assert report["verdict"] == "UNASSESSED"
json.dumps(report, allow_nan=False)
```

生产运行应对每一相邻对照独立提供 `PairEvidence`：

- `refinement_status="verified"` 及 `refinement_note`：说明实际保留基底/网格的加密，
  并引用可检查的工件。`refinement_kind` 可为 `nested`、`independent_refinement`、
  `joint_refinement` 或一般的 `explicit_refinement`。名义 `gmax` 增大不自动证明
  导模分支完整；非嵌套比较也需要独立加密证据。
- `spatial`、`modal`、`joint` 另需 `identity_status="verified"` 及 `identity_note`：
  引用共同物理场度量下的模式/简并子空间比较。频率排序或 Hungarian 谱匹配不能替代此证据。
- 每一对仅检查本地加密身份。独立固定 `k` 求谱不必先认证整条能带；连续能带和拓扑
  仍需对应的跨 `k` 子空间证据。

外部证据由调用者负责真实性；`verified` 不是自动计算出来的布尔开关。
所有声明或快照中出现的观测量均须提供容差；纯诊断量应放 `metadata` 或独立工件，
不能依赖框架静默忽略它。缺失数值、非有限数值、单位/形状不匹配均不通过。

## 状态与范围

| 状态 | 含义 |
|---|---|
| `PASS_PAIR` | 一对数值在声明容差内且必需证据齐全；不是收敛序列 |
| `PASS_SEQUENCE` | 至少三层、最后两次连续比较通过；仅限这些参数、量和加密层级 |
| `NOT_CONVERGED` | 至少一个数值差异超过容差 |
| `UNASSESSED` | 数据、容差或必需证据不足；包括只有两层的序列 |
| `REPRESENTATION_LIMIT` | 所需物理模型不能在当前表示/接口内合法计算 |

序列保存所有相邻对照。早期数值差异可以被后续两次通过解决；早期缺证据或
表示限制不会静默消失。不假定误差单调，也不强行作 Richardson 外推。
未通过的低截断试验可单独保留，然后对明确接受的三个新层级建立新序列；报告须
展示这个范围选择及原有拒绝。例如时间边带不足导致未取得完整有限维谱时，应保留
拒绝记录，不能拿仅剩下的几个模式宣布整个谱通过。

**`Snapshot.limitations` 是阻断式字段。** 只要非空，该快照参与的比较会记为
`REPRESENTATION_LIMIT`；把它纳入序列也会阻断序列认证。适合放置“扩大模态窗口后出现
辐射模式，而当前动力学没有合法开放闭合”这种实际障碍。
“本例只取三个 `k` 点”“没有验证拓扑”“使用有限电场投影”是范围备注，应该放
`model_scope` 或 `metadata`，不要放进 `limitations` 导致所有时间加密比较被误阻断。
单个观测量确实无法表示时，可使用
`Observable(None, status="representation_limit", note="具体原因")`。

## Floquet 谱与完整传播算符

对周期 `T` 和约定 `exp(-i*omega*t)`，乘子为 `mu=exp(-i*omega*T)`。
`compare_floquet_multipliers(mu_a, mu_b, period=T)` 要求两个完整等维谱，使用
Hungarian 分配比较复对数圆柱上的距离，分别报告：

- 相位频率误差：`abs(arg(mu_b / mu_a)) / T`，即模 `2π/T` 的准频率差。
- 增长率误差：`abs(log(abs(mu_b)) - log(abs(mu_a))) / T`。

输出的有符号相位差是乘子相位差；在上述时间约定下，它与实准频率差符号相反。
配对只用于谱集合距离，返回的物理/子空间身份仍是 `not_assessed`。不能据此认证
简并子空间、EP 本征向量、绝对展开频率或跨 `k` 连续能带。

`compare_propagators(U_a, U_b, coarse_basis_id=id, fine_basis_id=id, metric=M)`
另比较完整复数一周期算符的差范数。两边必须声明同一非空基底标识；可提供正定
Hermitian 度量 `M`，否则只使用该坐标下的 Euclidean 范数。非正规矩阵可能具有相同
本征值而传播行为不同，所以完整算符/实际场演化是必要的补充。该范数也不是开放性、
长期稳定性或空间完备性的证书。不同基底须先通过外部物理映射对齐，不能共用伪造的 ID。

缓存应记录实际静态求解来源、物理合同、全部数值控制、输出内容哈希和动力学源码哈希。
读取时验证合同与数组，不要把运行结束后计算一次文件哈希误称为缓存有效性检查。
历史来源与当前脚本不一致时，保留旧来源并说明复用依据。

## Bloch 坐标折叠与有限 Fourier 支撑

把 `k` 折回第一 Brillouin 区时，周期场的 `G` 标签必须反向移动，才能保持物理
平面波 `G+k` 不变。有限 `G` 截断通常不在这种移动下封闭；相近的频率不能保证
折叠边界处是相同的物理场。
`continuous_bloch_momenta(base_k, reciprocal_offsets)` 只连续相加，不自动折叠。
`compare_reciprocal_field_charts` 核查两点相差整数倒格矢，并在**完整 `G+k` 支撑并集**
上比较场；不会只取交集而丢掉截断误差。结果分别给出归一重叠平方、相位对齐距离、
两侧缺失支撑的范数占比。倒格基矢按列传入；`z`/分量的共同正度量权重由调用者预加。
这些指标可作为场身份的证据之一，不能替代严格 QNM 度量或多模子空间比较。
