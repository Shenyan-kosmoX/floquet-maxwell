# 负实频辐射、有限窗口因果连接与Science基底诊断

2026-10-14。继续完善自有Floquet适配，保持Legume安装和先前两篇基准数据不变。
本轮实测取得两个推进和一个明确的基准误差来源，但没有将有限近似认证为完整
开放Maxwell求解器。

## 正负频率的辐射谱现在有实际场验证

新增`reality.py`。对+k正频模式与独立−k正频模式的H场，逐个倒格矢按G→−G
映射并取复共轭，在共同物理积分网格拟合原生坐标变换`N=P T`。
只有场残差、矩阵酉性、秩、模态频率以及两种积分窗都通过，才允许将
负频谱矩阵写成`R_negative(+k)=T R_positive(-k)* T†`。
没有把白化后的坐标变换误用于原生归一化，也没有猜测TE/TM复振幅的相位。

Science只额外求解一个−k点，模式通过全窗口场重叠选择；LPR Γ模式复用缓存。
实际映射误差为：

| 算例 | H场变换相对残差 | 原坐标酉性残差 |
|---|---:|---:|
| LPR Γ A2g | 3.9e−14 | 3.1e−15 |
| LPR Γ Eu双模 | 1.7e−13 | 2.2e−15 |
| Science第9点双模 | 7.1e−13 | 4.0e−15 |

这个能力覆盖**实轴通道谱矩阵与相干功率**，没有提供未经验证的负频复通道相位，
也尚不是复频retarded解析延拓。

用它重新检查Science第9点原先保存的四个强调制Floquet状态，正负边带的
有效权重均覆盖到约`0.9999999995`。保持原本征矢不变，重新评价频率依赖辐射后，
模型输出功率为冻结预测的 **1.177、1.181、1.094、1.048倍**。
这是对原冻结假设的量化检查；不能把这个比例直接乘到Imω上宣称极点已修正。

入口：[原生±k验证](../results/native_reality/report.md)、
[双符号边带复核](../results/signed_sidebands/report.md)。

## 原生耗散谱到因果模型的受控连接

新增`spectral_bath.py`，接收明确指定频率窗口、正权重积分和谱矩阵，构造
被动的振荡辅助态，实现

    D_eta(z) = (2/pi) Σ_j w_j Γ(ν_j)/(eta+iν_j−iz)

在积分与展宽适当收敛的窗口内部，实轴Hermitian部分趋向`2Γ(ω)`。
反应性实部随同一核产生，不另加自由拟合频移。`memory_pencil.py`精确消去这些
声明的辅助态，在每个复侧带`z+m`处评价核，支持小矩阵非线性求根和增广场重构。

独立解析常数谱积分、上半平面Cauchy关系、能量、完整辅助态谱及Schur重构均通过。
四态完整乘子相对独立ODE误差`2.46e−13`；增广场重构误差`1.08e−13`。
这些检查验证有限因果模型及数值实现，不证明真实开放光子连续谱可被任意有限核替代。

本轮还实际采样了LPR Eu一个坐标的原生正频耗散，作为连接实验。Γ点该标量
例使用明确共轭对称补全；窗口外设零和有限展宽都是记录在案的近似。
固定窗口/展宽下，正频积分点16→32→64→128逐渐稳定，静态局部根收敛到约
`0.51198124−0.00544266i`（驱动单位）；改变窗口后变为约
`0.51566193−0.00561585i`。原冻结参考约`0.499972−0.005333i`。

**这说明反应性频移对缺失的带外信息和参考约定很敏感。** 小矩阵残差很小，
不代表有限窗口产生的实频移就是原结构的物理修正。本轮未加counterterm强行
拉回Legume频率、未选择展宽去拟合论文，也未把局部seed搜索冒称完整谱。
这些数据用于决定真实辐射自能还需要哪些信息。

入口：数学合同（历史材料 `spectral_bath_design.md`；见[发行说明](../../docs/RELEASE.md)）、
[独立验收](../results/spectral_bath/report.md)、
[实际原生谱连接与窗口敏感性](../results/native_spectral_completion/report.md)。

## Science静态子空间断裂的原因更明确了

此前30点路径中两处物理场保真明显降低。本轮只取5个有关k点，保持同样的
Legume空间基底参数，将输出模态28→80；再将层内/外积分每段8→32阶，
外部窗口±1a→±4a，分别检验谱窗和积分误差。

| 诊断 | 结果 |
|---|---|
| 最差边目标投影到相邻点全部28模 | 最小重叠平方0.574 |
| 扩到80模 | 提高至0.736，仍不完整 |
| 同外部窗口内积分8→32阶 | 几乎不变，约1e−4差异 |
| 扩外部积分窗到±4a | 不能恢复连续性 |
| 相邻k的参考导模集合 | TE2/TM3跨截止，部分基函数进入或退出 |

最差边消失的一条TE2基函数，原本承载某目标模式约 **22.26%** 的系数权重；
另一处新增的TE2行承载目标模式约4.06%和9.23%。这解释了为什么相邻点总体
矩阵维数相近甚至相同，物理场却可能难以连续追踪。

因此，输出谱窗不足确实贡献了一部分误差，但仅增加输出模式、细化积分或
重排模式标签都无法完全解决。这里发现的是**当前导模参考展开在这些参数处的
截断稳定性问题**，不据此断言Legume库存在错误，更不以新高频模式替换论文目标。

下一步应在既有Legume接口内检查参考层和导模集合的稳定性、完整性，
让送入Floquet的静态子空间先具备可靠跨k延拓。这个证据也说明，不能将当前
Science差异全部归咎于时间谐波组装。

入口：[原因诊断](spatial_window_review.md)、
[对应图](../results/spatial_window/spatial_window_diagnosis.png)。

## 验证与剩余工作

本轮完整回归 **315项通过**，记录在`results/signed_causal_pytest.xml`。
新增原生实轴映射、因果谱积分和Schur本征问题均有独立检查，Legume库未改。

仍需解决：带外辐射谱与反应性参考、真实连续谱的retarded共振支路、泵浦改变
内部—辐射耦合的项，以及Science静态参考子空间的稳定性。
两篇论文的验收状态暂不升级：LPR平方趋势成立但系数未对齐；Science局部
强调制增长存在但窄隙与完整动量隙尚未通过。
