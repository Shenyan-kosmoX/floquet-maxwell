# 通用参考基底策略实测：局部改进成立，完整路径尚未通过

日期：2026-10-14。**通用原生Legume接口、物理场并集比较、基底变化诊断和条件化k加密均已实际运行；本轮没有得到可接受的Science连通路径配置。** reference ε=12改善了原先最坏的局部区间，但把一个有显著权重的参考导模截止移动到了Γ–X的较早位置，不能视为全局修复。

主证据：[19点Γ连续路径及剩余失败](../results/basis_stability/probes/Gamma_connected_reference12.png)。完整原始谱、H场、坐标、导模标签及判据位于 `results/basis_stability/probes/`。运行器为 `scripts/probe_reference_candidates.py`，没有修改安装的Legume，没有调物理材料或按最近频率贴论文。

## 实际完成了哪些受控计算

Science物理结构固定ε=16、r/a=.3125、h/a≈.44452347。对同一6点集合（Γ和此前两个失配区间及邻点）依次使用reference ε=16、20、24、12；gmax=5.1，xy-even导模索引上限24（实际12个family），保留60个模式。每个候选在整组k上使用同一个reference值。真实几何/介电分布由`physical_signature`在reference设置前后及原生求解后核对。

Γ种子通过旧物理H场与A2g候选匹配；64–73 THz只是这条外部回归基线的初始选择条件，不是通用策略的评分目标。旧截止附近的每个k平面仅作为敏感性比较，不能被当作准确物理真值。真正局部连接固定左端物理H，从相邻k依次传播；随后又从Γ进行了实际连续路径验证。

另有非论文fixture B：r/a=.23、h/a=.36、物理ε=12，两个k由参考TE2解析截止位置自动生成。种子按实际H场在对应Fourier通道的范数份额选择，没有预设目标频率。它验证同一策略是否能检测另一几何的截止问题。

所有原生重任务顺序执行，数值库线程上限为2；数据写入独立候选目录，旧基线没有覆盖。

## 从Γ连接后发现：ref12移动了截止

从原Γ物理场重新出发，在reference ε=12下实际计算Γ→X→第二问题区间的连续15点。仅用相邻物理H子空间传播，selected门槛0.9、竞争margin0.08，完整窗口门槛0.98，变化导模行权重上限0.02。种子与旧Γ场的capture为0.998721。

第一次连续路径存在三条问题边。两条处于kx≈0.449–1.346，目标两模重叠偏低，但完整60模窗口capture约0.999，变化导模行权重只有10⁻⁵–10⁻⁴。这类结果不能直接归为基底不完备，可能只是k采样较粗或真实模式混合。

第三条kx=1.795195802→2.243994753同时有窗口缺失和高权重行消失，因此不能用盲目k加密掩盖。

### 通用midpoint planner的实际验证

`plan_k_refinement`第一轮建议边[1,2]，第二轮建议边[2,3]；其返回的k坐标与实际算出的四个新增点逐项完全一致，匹配事实已写入每轮summary的 `generic_midpoint_plan_matches_actual_computed_points=true`。没有重复求解这些已完成的点。

两轮各增加2点后共19点。原来那两条“完整窗口足够”的问题区间，最差selected capture提高到 **0.918373**，完整窗口capture保持约0.9996以上，达到本次局部连续性标准。这个操作有效解决了粗采样导致的模式旋转问题；没有改变物理种子或材料。

最终仅剩原第三条问题边：

| 指标 | 剩余失败值 |
|---|---:|
| kx区间 | 1.795195802 → 2.243994753 |

此处native family4（TE2）在G=(-2π,0)上的 `|G+k|`从 **4.487989505** 降到 **4.039190555**，穿过对称εref=12参考均匀薄膜的解析截止 **4.261758432**。截止公式为 `g_cut=pπ/[h sqrt(εref−εair)]`，这里p=2、h/a≈.44452347、εair=1。

该单行对目标二维子空间的规范不变最坏权重约 **0.123974**；单个原生模式的系数平方分别约0.084880和0.039094。其他同时丢失的高阶导模行只贡献极小权重。因此有直接证据表明：reference ε=12让旧失配区间更顺畅，却把重要TE2截止挪到了更早的Γ–X区间。它没有真正消除guided-only参考空间的这一限制。

对应解析和系数证据在 `reference12_cutoff_evidence.json`。最终剩余失败后，后续候选保持空心/未确认标记，不送入下游Floquet当作已确认的两模身份。

## 非论文fixture和独立正例

fixture B在reference12时，跨解析截止的selected capture约0.547498、完整窗口约0.894396。改为reference20后，局部指标提高至0.997151和0.999970，但与原左端物理种子的capture仅0.763532，且未做独立空间加密；策略因此仍拒绝。这个例子表明通用设施不会因为曲线更平滑就宣称成功，也没有依赖Science特定坏点索引。

另一个独立、可接受的解析正例是[uniform slab验证](../results/reference_infrastructure/summary.json)：原生TE0频率与解析边界匹配的最大误差约2.2843×10⁻¹⁴ f·a/c；gmax2.1单family→gmax3.1四family的真实加密给出约9.91×10⁻¹⁵相对频差和fieldcapture=1；z积分16→24节点范数变化约2.22×10⁻¹⁶。它在严格限定的slab采样范围内得到 `ACCEPTED_SAMPLED_CONFIGURATION`。

因此已经具备**确实可通过的独立正例**与**必须拒绝的真实复杂结构反例**。主代理最终统一回归为401项通过，记录在 `results/basis_stability_pytest.xml`；这不把Science剩余的物理/数值失败改写为通过。

## 交付结论

本轮通用设施已验证能区分：输出窗不足、参考导模截止、普通粗k旋转、跨参考的身份变化，以及独立空间加密是否真的保留同一物理场。最终Science状态仍为 **NO_VALIDATED_CONFIGURATION**，不是“已修好跨BZ双带”。

下一步必须针对会消失的、具有显著目标权重的参考导模子空间本身展开受控工作；不能仅增加输出numeig、改变参考ε直到图变平，或重设标签来宣称根治。本轮没有扩展失败路径上的全空间加密，没有修改Legume库，也没有重画论文Floquet带来掩盖问题。
