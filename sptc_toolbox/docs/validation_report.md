# R1 冻结共同辐射浴：独立验收

日期：2026-10-14。验收脚本 `scripts/validate_open_backend.py` 使用公开的 `FrozenRadiationBath` / `FrozenOpenSystem` 接口，不修改Legume，不执行新的空间本征值求解。真实数据来自此前生成的可信本地LPOR Legume缓存Eu双态 `[3,4]`。

运行命令：

```powershell
.venv\Scripts\python.exe sptc_toolbox/scripts/validate_open_backend.py
```

本次验收对象是有限维、弱辐射、冻结共同浴模型

`u''+2Γu'+K(τ)u=0, Γ=CC†≥0, τ=Ωt`。

它保留完整的非对角辐射干涉，不额外加Γ²补偿。所验证的能量为

`E=(v†v+u†Ku)/2`，`Ppump=u†K'u/2`，`Prad=2v†Γv=|√2C†v|²`。

所以瞬时预算为 `dE/dτ=Ppump−Prad`；非稳态周期积分是 `ΔE=∫(Ppump−Prad)dτ`，并非强行令pump等于loss。Floquet周期包络满足 `2Im(w)〈E〉=〈Ppump〉−〈Prad〉`。能量和功率是该降阶模型的无量纲量，不是原始Legume接口直接给出的SI瓦特。

## 验收构造与已取得结果

1. **解析共同通道亮/暗态。** 两个简并模K=ω0²I，Γ=γ/2[[1,1],[1,1]]。解析暗态频率±ω0，亮态频率±√(ω0²−γ²)−iγ。实际频率误差约2.2×10^-16。只保留Γ对角元会使两态都衰减，错失暗态；该反例用于区分共同浴和独立线宽，不是把真实Eu双态人为解释为亮暗分裂。
2. **非对易被动性。** 使用正Hermitian K与复PSD Γ，KΓ≠ΓK。所有静态极点虚部为负，任意给定初态的无泵能量单调下降；独立时间积分能量余额误差约3.5×10^-15。
3. **±频率/cross-k合同。** 复K、Γ分别共轭构造−k伙伴；`w(-k)=-w(k)*`完整谱匹配误差约7.8×10^-16。该项是代数contract，不是新的真实空间±k计算。
4. **驱动完整谱。** 由基本二阶方程单独调用solve_ivp产生一周期传播子，从不调用生产`.matrix`或Fourier组装。逐一匹配全部2n个乘子并保留重数，synthetic驱动误差约6.8×10^-14。
5. **规范协变。** 同时变换K、K'、Γ和状态；常数模态unitary变换后乘子误差约2.0×10^-14，逐通道辐射复振幅误差约3.5×10^-18。通道phase变换保持Gram和总功率。本项不允许忽略时间依赖基底的connection项。
6. **参量增长符号和预算。** 一个明确的合成单振子同时出现增长/衰减，全部乘子和Floquet能量平衡通过。其参数是验收fixture，不是论文泵浦参数。
