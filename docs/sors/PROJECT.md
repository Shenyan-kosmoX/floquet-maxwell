# 研究范围与方法

Floquet–Maxwell 研究周期光子结构中的实际时间调制，主要空间平台是面内二维光子晶体薄膜。Legume 提供静态几何、模式、场和原生辐射数据，工具箱连接材料投影、Floquet 动力学、有限时间响应与外部激励。

项目已有多条从真实空间场到动态观测量的计算路径，包括 W1 波导中的行波输运、AlGaAs 薄膜的张量选择规则、逐晶胞随机幅相的跨动量耦合，以及静态 Green 数据支撑的侧带散射。[能力地图](CAPABILITIES.md)说明各接口，[案例总览](CASES.md)展示论文结果与独立基准。

## 空间数据与可复用模态包

空间适配保留 Legume 的原生几何和数值求解，支持多层 Circle、Ellipse、Poly、层背景和整层材料区域。`ModePackage` 将频率、投影、辐射、场、坐标、单位、损耗归属和来源保存在统一格式中。真实几何与数值参考层分别记录，方便保持模型固定并比较空间基底。

局部固定 k 的求解可直接从完整的选定模式簇开始。连续能带、波包跨区输运和拓扑分析可使用公共物理场度量、简并子空间输运与 Bloch sewing 连接不同 k。场重建使用同一基底中的复振幅，得到 E/H/D 的空间与时间分布。

## 材料与调制

调制由实际场的重叠积分进入动力学。标量区域投影覆盖多区域、多时间 Fourier 阶、DC 和区域相位；张量投影保留非对角介电分量及复相位。行波接口连接多个 Bloch 动量；逐晶胞驱动允许固定随机幅度、相位与不同时间阶的独立空间图案。

静态结构保持周期性。固定随机图案每个时间周期重复时，可作为重复超胞的 Floquet 问题；无限无序样品和非周期时间噪声对应其他统计与时间模型。一般连续多 q 的 Fourier 输入已有表达和一致性检查，现有真实 Legume 投影入口覆盖单行波与逐晶胞图案。

无色散有限模态后端通过电质量矩阵构造 `K = W M(t)⁻¹ W`，保留正负频率状态，并与直接时间积分比较。Lorentz / Drude 模块显式演化 D/B/P/J 材料辅助场，支持介电背景及振子强度调制；实际图案区域的 ADE 已与共同坐标的辐射记忆模块连接。

## 开放系统、激励与散射

开放辐射模块从 Legume 复通道构造共同通道阻尼，保留模式间干涉。共同实频采样、实际 ±k 的负频映射、有限谱窗因果浴及 Schur–Floquet 消元提供频率相关响应。冻结共同通道与有限谱窗记忆是可选择的动态模型，各案例说明使用的频段和通道。

通用有限算符接口提供广义左右模态、简并子空间归一化、非线性简单极点导数留数和显式 H/B/C/D 散射。开放色散薄膜的边界基准把这些计算连接到 Fresnel、复频极点和外部散射。二维图案薄膜还提供 Legume 场基底与 Meep 静态 Green 数据的混合路线，支持背景增广、多频输入、内部谐波场及出射端口重建。

材料吸收、辐射损耗和泵浦能量交换各有归属。外部功率使用相应端口规范；正负频率在半泵处重合时，实场相干求和保留入射相位对增益的影响。频率、增长、转换效率与场形因而可以在同一模型中相互检查。

## 验证围绕物理问题展开

张量选择规则使用对称性、独立空间积分和相位控制；波包输运比较场重建、主峰和远尾；增长率比较正负频率谱、独立时间演化与损耗；散射计算核对源功、出射通量及静态响应。

分层工作流分别处理原生空间基底、保留模态与动量窗口、时间 Fourier / 时间步和观测网格。精度相对于带隙、失谐、线宽、增长或传播时间判断。已有结果分别记录机制证据、定量敏感性和近似模型，方便选择下一步值得投入的计算。

## 继续发展的方向

当前方向包括任意图案薄膜的复频辐射映射、多衍射级和跨动量开放散射、连续多 q 调制的通用空间适配，以及依赖完整 Bloch 子空间的拓扑观测量。这些工作可继承现有投影、动力学、场与验证模块；通用 QNM、色散及散射算法和对应基准也可独立使用。

详细历史结果及原始条件见[研究归档索引](../../sptc_toolbox/README.md)。
