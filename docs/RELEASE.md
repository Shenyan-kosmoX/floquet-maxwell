# 发行内容与结果复用

这份源码发行包含 17 类工具箱能力、20 项文献或独立基准案例，以及相关计算模块、验证程序、报告和轻量计算结果。案例目录连接模型说明、使用环境、检查方法和已有成果，便于从一个具体问题开始使用或继续贡献。

## 结果与来源

`sptc_toolbox/results`、`ptc_fig4/results` 和其他案例结果目录保存既有研究记录。文件名中的日期与历史 manifest 对应原始计算；本次发行的 commit 标识这份公开快照。新环境复跑的结果另见 `docs/release-verification.json`。

各案例的 `results.records` 指向报告；`results.artifacts` 指向随发行提供的主要产物。带有 `availability: not_bundled` 的条目说明材料的取得方式。历史报告还会提及较大的时域场数组、本地求解缓存或论文原图；这些材料有助于说明研究来源，源码发行主要保存相应摘要与生成程序。完整原始数组目前没有公开下载地址。

NumPy 数组、CSV、JSON 和自有计算图可以结合相邻的参数记录复用。Pickle 缓存由使用者在本地重新生成。论文图像和补充材料可从案例中的 DOI 页面取得；对照图明确保留论文图号和计算范围。

## 环境选择

基础模块和 Legume 使用根目录 `pyproject.toml`。球阵列对照可额外安装 `.[sphere]`。直接 Meep 算例使用 Linux 或 WSL 下的独立环境；`environments/meep.yml` 提供版本入口，具体命令和边界设置见对应案例报告。COMSOL 比较需要单独安装软件和有效授权，可选 Python 桥接工具为 MPh。

大部分历史脚本在源码目录运行，其中一些沿用历史默认输出。继续计算时先查看脚本参数与案例说明，选择新的结果目录。快速开始的 Jin 计算、绘图和验证入口已支持独立目录，并在已有目标结果存在时给出提示。

本次发布调整了 Jin 入口的默认使用方式：计算保留已有结果，验证要求明确 `--output`，绘图只有指定 `--paper-image` 时才制作论文并排图。对应数学模型、历史结果和判据保持原样。COMSOL 单元脚本新增 `--models` 和 `--output`，便于使用自己的工作目录；这两个可选入口已做语法检查，本次没有启动 COMSOL 重算。

## 发布校验

SORS 自动检查维护项目与案例清单的字段、引用关系及文档入口；软件测试检查相应接口和物理控制。运行结果的适用范围由每个案例的模型与验证记录说明。欢迎在 issue 中附上案例 ID、版本、环境与可复现命令，让讨论容易定位到同一份计算。
