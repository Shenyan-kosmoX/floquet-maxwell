# 正式版 Fig. 3 的 Legume 复现尝试

日期：2026-10-13。目标论文：[10.1002/lpor.71318](https://doi.org/10.1002/lpor.71318)。

项目目标是完善可复用的 Legume / Floquet–Maxwell 工具箱；本论文仅作为
验证案例，不沿本文继续发展课题。文献趋势一致可以接受，但工具箱内部数值正确性
仍需独立验证，见工作区 `TOOLBOX_VALIDATION.md`。后续不再制作 Colab。
开放辐射优先复用 Legume 已有的损耗与复通道耦合导出。

这篇论文确实有适合 Legume 的面内周期结构。当前已建立可运行的
**Legume 静态 Maxwell 模式 → 原生介电矩阵的时间调制 → Floquet 本征问题**，
得到与论文相似的环状电场和弱调制平方频移。定性机制已有支持；
频移系数仍与论文约差 16 倍，作者选定模式及开放 QNM 本征值尚未对齐。

## 使用正式版，而非旧预印本

网页 HTML 存档有长度截断，来源清单已注明；补充材料 PDF 完整。

## 得到的结果

![与论文对照及收敛](results/fig3_attempt/fig3_attempt.png)

最低 A2g 候选模的电场在 xy 平面呈单环，中心暗；xz 截面有两个离轴热点，
与论文绿色模式图相似。自定义参考介电常数 16、gmax=7.1、8 个请求导模阶下，
循环频率为 **377.4476 THz**。空间平均介电参考给出 **385.6061 THz**，
两者约差 2.1%，因此不声称静态频率已完全收敛。

在当前方晶格 Γ 点假设下，这个模式是第一衍射阈值以下的对称保护 BIC。
Legume 输出的极大 Q 来自近零数值线宽，不能解读成已精确求出了一个有限 Q 开放共振。

在原生逆介电矩阵投影的三模计算中：

| 检查量 | 数值 | 说明 |
|---|---:|---|
| 弱调制频移 log–log 斜率 | 1.99991 | 与平方律一致 |
| C，定义 ΔRe(ω)/Ω=Cϵ² | 0.0165720 | 原生逆介电投影；非自由拟合参数 |
| 论文绿色标记 C | 约 0.27±0.05 | 从公开图像粗读，非作者原始数据 |
| 论文 / 当前频移系数 | 约 16.4 | 定量幅度尚未对上 |
| 场积分与直接 Legume 材料微扰的导数相对误差 | 3.12×10⁻⁹ | 独立改变物理 ε、保持相同导模参考 |
| Floquet 与一周期 ODE 的最大乘子差 | 2.17×10⁻¹¹ 以下 | 验证有限投影系统的时间求解 |
| 二阶解析展开与 Floquet 频移的最大相对差 | 3.63×10⁻⁴ 以下 | 包括最小幅度处的相减精度影响 |

时间谐波从 3 增加至 11 个，总频移在 ϵ=10⁻³ 时稳定在约 1.6572×10⁻⁸。
此外，将保存的静态谱扩至 80 个模式、保留其中全部 7 个 A2g 模式，
C 从 0.0165720 变为 **0.0165577**，仅改变 0.0866%。
进一步增至 gmax=9.1、10 个请求导模阶后，7 个 A2g 模式给出 C=0.0165727，
与上档相差 0.0908%。7.1 档最终保存 81 个输出模以保留末端的完整简并对，
不改变上述 A2g 结果。
因此，这批已检查的高频模式遗漏不能解释约 16 倍差距；
这不等于证明 Legume 的导模基底对开放问题完备。

## 为什么这次更接近你要求的开发方式

几何由 `Lattice / PhotCryst / Circle` 建立；静态本征值、辐射估计和场来自
`GuidedModeExp / compute_rad / ft_field_xy`。柱子的 Fourier 卷积直接调用
`Circle.compute_ft`，重建的逆介电矩阵与 Legume 原生矩阵的范数差为 7.47×10⁻¹⁴ 以下。
没有另外开发一个独立空间 Maxwell 求解器。

时间耦合来自原生 D 场和实际介电矩阵，未用任意耦合常数去贴论文曲线。
正、负频率分支都保留。逆介电矩阵的时间依赖在当前空间截断中直接计算，
也保留了二阶平均项；仅用一阶重叠平方替代会产生不同二阶结果。
独立数学审查核对了符号、1/2、角频率换算和场归一化，未发现可以支持
“补一个 16 因子”的实现错误。

## 差距意味着什么

本次已经使用论文的常数 ε=16，**不能再把当前差距归咎于 Ge 色散参数**。
对已离散的 Legume 模型，时间求解、场耦合的一阶静态响应和二阶展开相互吻合。
这些检查支持程序在所声明近似下的自洽性，却没有证明它等价于作者的开放 QNM RSE。

剩余关键问题是模式身份与 Bloch 设置尚未唯一对齐、导模参考仍敏感、
以及作者的开放模归一化和辐射连续谱未被当前 Hermitian 子空间完整包含。
Legume 的微扰辐射损耗也不能自动成为每个 Floquet 边带的严格出射边界。
本次主图没有用附加损耗或材料调整掩盖这些区别。

这篇可作为 Legume 时间扩展的一项基准：几何简单、材料明确，
能检查场形、平方律及实际耦合矩阵。工具箱后续验收按功能缺口选择最合适的
简单基准或文献，无需按本文图序推进；严格对照本文某个开放模式时才需要
继续确认作者该模式的具体设置。
