# 正式Fig.3a绿色圆圈的粗略读图

来源：Wiley正式Fig.3原图 `literature/published_fig3.png`（480×424像素），Fig.3a绿色空心圆代表周期nanorod metasurface。图像SHA256：`2b4de3553e5ad0081c0d570cb4ceee12d6f92a22823275650830a4e6b4084b17`。完整原图保留上下文：上半部分为非平面结构的二次标度比较，下半(c,d)为另外的slab例子，不能混读其幅度轴。

本文和CSV都是**图像数字化近似，不是作者原始数值数据，也不是计算结果**。没有用拟合抛物线生成“数据点”。CSV保存11个可辨认绿色圆圈中心、原图像素坐标、选取窗口、绿色像素数量及质量标记。由于高幅度端空心圆与其他颜色标记重叠，只选取其中一个接近10^-3的端点，不尝试逐点拆出所有重叠标记。

## 原图轴和校准

- 原点为整张图左上角，x向右、y向下；面板a绘图区约x=36–301、y=15–220。
- 横轴标注为 **Modulation amplitude**，log刻度：x≈94对应10^-4，x≈301对应10^-3。其幅度符号在全文中为介电调制的绝对幅度ϵ；图中没有写ϵ/εu、百分比或折射率相对调制。**不除以16，不转换为m，不借用上一篇论文的定义。**
- 纵轴是 **ΔRe(ω̃)/Ω**，log刻度：y≈16、81、147、212分别约为10^-6、10^-7、10^-8、10^-9。caption解释为调制非零相对于静态共振的实频差。
- 使用端点线性log校准：`log10(ϵ)=-4+(x-94)/207`；`log10(ΔReω̃/Ω)=-6-3(y-16)/196`。中间十倍刻度用于视觉交叉检查。
- 绿色颜色辅助条件（8-bit RGB）为 `G-R>25, G-B>15, R<190, G>75`。先在原图上识别空心圆，再由其弧线的左右/上下边界估计圆心；未对曲线进行拟合。图上绿色三维柱阵插画也有绿色像素，必须排除，不能全图按绿色连通区域自动当作数据。

直接逐点计算 `C_i=(ΔReω̃/Ω)/ϵ²`，得到约0.268–0.277，中位数约0.272。这仅是数字化点的比值统计，**没有用C反推曲线或填补缺失点**。合理报告为

`ΔReω̃/Ω ≈ (0.27 ± 0.05) ϵ²`

其中±0.05为保守读图不确定范围，不是作者给出的误差条或统计置信区间。CSV中的多位小数用于保留坐标换算可复核性，不代表相应物理精度。

## 不确定度和使用边界

圆心定位约±2像素；最右端重叠点约±3像素。刻度和plot边界定位还约±1像素。纵轴每十倍仅约65像素，因此2像素相当于约7%的纵值变化，3像素约11%；横轴约207像素/十倍，2像素对应约2.2%的幅度变化。结合轴校准、圆圈与其他颜色交叠，比较单个纵值宜允许约15–20%，C也宜按约20%量级误差看待。

从这些点可稳妥读出：ϵ约10^-4至10^-3时，绿色频移约3×10^-9至3×10^-7，呈二次量级。图3使用Ω=100 THz（角频率记号），但比较无量纲纵值无需额外2π转换。不能用本次有限分辨率图像证明精确二次系数，也不能据此调节空间模式耦合以强制吻合。
