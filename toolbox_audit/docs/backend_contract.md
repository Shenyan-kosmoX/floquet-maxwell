# Legume 开放 SPTC 后端：审计后的实现合同

本文件是具体设计与验收边界；除报告明确标注的已有模块，不代表代码已经实现。
继续使用 Legume 的几何、模式、介电矩阵、场和辐射数据，保留当前已验证的
一般 Fourier 组装核心，不将静态后端整体替换。

## 一致的 Maxwell 表述

无色散瞬时介质首先使用 D/B 状态，或与它严格等价的广义 Maxwell 方程；
有色散时增加极化和电流辅助变量，明确调制的是背景 ε∞、振子强度、共振频率
还是其他项。静态损耗不能通过把常数复 ε 塞进瞬时实时间模型来模拟。

建议以物理时间的一阶形式记录：

    i ∂t[B(t) y(t)] = A(t) y(t)

或显式转换为已验证的状态 x 后 i∂t x=M(t)x。谐波形式为：

    Σ_n [A_(m-n) − (ω+mΩ) B_(m-n)] y_n = 0

频率乘在输出侧带 ω+mΩ 上。若将含时 B 逆掉，必须说明 x 与原场的关系，
不能对原变量遗漏 B 的时间导数。当前固定 H/D 投影保留为一种受限实现。

## 数据与模块边界

| 模块 | 必需输入/输出及责任 |
|---|---|
| `SpatialBasis` | 几何、k/晶格、物理模式及基底标签、E/D/H、Gram 度量、归一化、单位、参考层和截断。支持不依赖任意本征矢相位的变换。 |
| `Modulation` | 各区域掩膜/空间 Fourier 分量、幅度、相位、时间谐波、DC、调制材料项。显式记录 `(Q,p)` 和 reality 约束。 |
| `MaterialProjection` | 完整保留模态间的耦合块，含非对角项；必要时保留材料辅助变量与非单位 B。输出能追溯到场及材料导数，不拟合论文曲线。 |
| `RadiationAdapter` | 通道标签、相位、评价频率/动量、同频复耦合，以及有明确来源的 retarded 自能或声明有效范围的常数近似。 |
| `FloquetOperator` | 保存全部空间/时间/电磁/材料索引；组装标准矩阵、广义本征问题或频率依赖非线性算符。保持不同问题类型清楚分离。 |
| `Spectrum` | 原始左右本征信息、方程残差、截断、物理副本与代数重数、EP/简并标记和模式跟踪置信度。没有度量与谱隙依据时不报告拓扑不变量。 |

三类调制共用 `ε(r,t)=Σ_(Q,p) ε_(Q,p) exp(iQ·r−ipΩt)`。
实瞬时介质满足 `ε_(Q,p)*=ε_(-Q,-p)`，保留 p=0。
同步及单胞内重复相位图案保持原晶格 Bloch k；行波连接 `k_out=k_in+Q`、
`m_out=n_in+p`，按相容性选择超胞或动量链，非相容截断需单独收敛。
单个 p≠0 材料谐波可以非 Hermitian，不能误套现有空间 Gram 的 PSD 校验。

## 开放边界与非厄米性

推荐主路线是 Hermitian Legume 内部基底加辐射连续谱消去得到的自能。
有真 QNM 数据时可用另一个 adapter，但不得混用 Hermitian 能量内积与 QNM
留数归一化。保持两类基底的字段、度量和适用范围明确。

在适用的一阶局部表示中，静态逆响应可写成
`νI−H_ref−Σ_R(ν,k)`。正频率实轴被动背景的窄带表示为
`Σ_R≈Δ−iΓ`、`Γ>=0`。复杂频率和负频率应按整个 Maxwell/材料算符的
reality 与 retarded 解析延拓处理，不能逐项盲用正频率公式。

**第一阶段：** 隔离/近简并子空间中的弱辐射、共同频率窄带近似。
保留公共通道的完整 Γ，验证亮暗态、功率、相位/基底协变、被动性和静态极限。
不能只删除当前 `diag` 就得到正确多模阻尼；Γ² 补偿与 W 不对易时须重新推导。
Legume 各模自身频率的原生通道导出不是自动可拼接的共同频率精确浴。

**第二阶段：** 复用原生辐射重叠内核，在共同评价频率获得各模式耦合，处理
衍射阈值、DOS、实频移 Δ 的来源与避免重复计数。分别对每个物理边带
`ν_m=ω+mΩ` 及其实际动量求值。保留吸收与辐射的不同来源。

**第三阶段：** 处理频率依赖自能的复杂频率延拓及非线性 Floquet 极点。
只有外部介质静止且系统—浴耦合也冻结时，消去浴的自能才在时间谐波上对角。
若内部调制影响了到辐射子空间的耦合，就需要允许非对角的 `Σ_mn(ω)`；
“仅背景静止”不足以忽略它。该项是当前后端重要的待验证近似。

开放非厄米系统可能有辐射衰减、材料吸收/增益和参数泵浦，三者不能用一个任意
复频率混合。泵浦造成的增长与负频伙伴相连；物理 reality 一般联系 `(k,ω)` 和
`(-k,-ω*)`，不能对所有破坏对称性的调制强制同 k 的对称配对。

## 模态度量与异常点

对标准矩阵，SciPy 的左右矢量及 L†R 可用于其坐标下的谱诊断。
对 `A r=ω B r`，需要对应的 B 度量及其参数依赖；对频率依赖 `A(ω)r=0`，
简单极点留数包含 `l† ∂ωA r`。其接近零、或核维数改变时，不能仍按孤立简单
极点处理。应保存子空间/Schur信息，数值本征矢标签不等于唯一物理模式。
Bloch 基底和度量随 k 变化时，拓扑比较还需物理场对齐及合适的连接；
不能只把不同 k 的系数列直接做欧氏内积。

## 逐项验收，避免共同模型的盲区

1. 时间代数：现有解析、均匀 Meep、全周期积分及相同输入外部矩阵对照保持回归。
2. 空间耦合：一阶导数、二阶曲率、完整跨模/区域相位耦合分别检验；模态数、
   空间基底与参考层分别收敛。仅一阶一致不能认证二阶或非对角项。
3. 静态开放：一个可解析的共同浴例子，加一个可解析/独立测得有限 Q 的真实结构，
   对复极点和相干辐射输出同时对照。严格 BIC 不适合作为唯一辐射验证。
4. 动态开放：在同一物理调制和边界下，用真正结构时域或独立频域 Maxwell 算例
   对照复频率、衰减/增长及边带场，确保独立参照没有复用同一降阶方程。
5. 三类调制：单区域同步→两区域相位→相容行波，分别检查时间原点不变性、
   相位差物理作用、动量选择规则和超胞/动量链等价；不能一次全扩后才检查。
6. 非厄米谱：正常简并保留重数，EP显式报告，错误跟踪有报警；只有这些和所需
   谱隙/度量满足后再验证拓扑功能。

各阶段验收的是所声明近似和数值范围，不能保证任意材料、频率及几何下均正确。
