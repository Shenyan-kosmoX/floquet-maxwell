## 已实现和实测的软件

`src/ptc_fig4/floquet_maxwell.py` 直接组装、求解非厄米 Fourier–Maxwell 矩阵，保存全部本征值、左右本征矢和副本。`materials.py` 包含含DC偏移的瞬时介质、精确Mathieu测试介质及具备极化辅助变量的Lorentz模型。`references.py` 独立积分二阶Hill方程和材料动力学，另含精确时间传输矩阵参考。`mode_tracking.py` 使用左右模重叠和整数Floquet gauge对齐，不依赖最近频率跟踪；简并处显式标记身份不唯一。

`static_modes.py` 是实际可运行的复频率非线性本征对求解器：用增广Newton求 `A(ω)v=0`，输出左右零向量、残差和频率导数配对。它已通过解析开放平板和色散Maxwell测试，但**没有把标准Legume的实频矩阵冒充Ge的严格开放算符**。求根使用固定物理残差尺度和有界搜索区域，避免把发散的材料极点或无穷远误认作共振。

`legume_reference.py` 用公开Legume 1.0.3 API建立空气中的实际有限高度圆柱，保存完整请求窗口的空间本征对和Γ点电磁场。新增的场对称性检查使用矢量/轴矢量变换和简并子空间，不根据频率接近程度指定目标模。

所有核心路径均为Python/CPU，不使用Meep。主依赖固定版本；当前环境版本见 `requirements-lock-windows.txt`，可移植安装用 `pyproject.toml`。代码、配置和参考版本记录于各运行manifest。可重新执行命令见README。

## 均匀 PTC：VERIFIED 的具体范围

约定：`exp(+ikx-iωt)`，`τ=Ωt`，`κ=c0 k/Ω`，状态 `(D_y,B_z)`；有色散时加入 `(P,J)`。Floquet对角项为 `−mΩ`。正虚部对应时间增长；折叠仅改变准频率实部。

主要连续扫描采用 `ε(τ)=4[1+0.12(1+cos(τ+0.37))]`。这是一项明确给定的均匀介质基准，**不是Ge材料或Fig.4**。

独立参考还包括：

- 零调制时所有静态正负频率及整数Floquet副本的完整谱，包含跨多个Floquet区的频率。
- 非零调制相位下的解析Fourier系数，验证IFFT/Fourier符号，避免仅用偶函数cos掩盖符号错误。
- `1/ε=(1+0.12cosτ)/4` 的**精确Mathieu**第一隙边界：[0.971092869718706, 1.031156742718772]；独立积分得到的边界最大差约1.4e−14。
- 通常 `ε` 为余弦的模型只与**弱调制Mathieu渐近**比较，保留DC造成的频率偏移，未混淆两种模型。
- 精确两段介质：ε1=4、ε2=9、占空比0.4、κ=1.25；时间传输乘子恰为 −1.5 与 −2/3，分别增长和衰减。
- 明确参数的Lorentz辅助场模型：所有四条物理分支与独立材料动力学的准频率最大差约1.08e−13，并检验 `det U=exp(−2πγ)`。
- 对增长Floquet本征模直接积分十个周期，比较完整复场及增长率，而非只检查本征值虚部符号。

原始证据：`results/homogeneous_quick/` 和 `results/homogeneous_high_precision/`；每个k点的NPZ包含全部谱、左右矢量、选中索引、独立单周期矩阵和残差。图为PNG和PDF。

### 严格区分矩阵残差、时域残差和截断精度

`results/time_reconstruction/` 在257个不与FFT网格重合的时间点重构完整 `ψ`、`ψ'`，直接检查 `iψ'−M(τ)ψ`。弱调制的RMS相对残差从N=2的4.8895e−4降到N=8的1.2907e−11、N=12的6.5663e−15；强调制m=.6且无DC时，从N=2的2.1720e−2降到N=16的5.1690e−9。这说明投影矩阵残差达到机器精度，并不表示未截断Maxwell方程同样准确。

`results/homogeneous_stress/` 保存600组低截断压力测试：330组通过分支筛选、270组明确拒绝。330组中只有239组达到1e−8乘子精度，另91组**FAILED该严格精度条件**；最大接受误差4.1066e−6。完整CSV和全部600组左右矢量、原始频谱已保存。不能把“筛选得到两支”当成收敛证书。

审查中发现并修复了一个实质错误：m=.85、无DC、κ=.9875、N=8时，仅凭固定频差去重曾把两个增长副本选作完整谱、漏掉衰减模。现在结合整数gauge对齐后的左右向量识别副本，扫描全部中心候选并检查类数；新增回归要求正确保留两支或明确拒绝。高截断N=16与独立参考一致。

## 开放复频率基准：VERIFIED，但仅为一维平板

精确开放平板在空气中的解析极点为 `ω=[πq+i log((n−1)/(n+1))]/(nL)`（c0=1），满足负虚部出射共振。3组实测根误差均小于9e−16；同时验证边界矩阵零向量、左零向量及Q。另对频率相关Lorentz Maxwell算符与独立四次多项式根比较。原始文件见 `results/open_slab_benchmark/`。

此基准验证复频率求根机制和出射符号；不验证Ge阵列的空间离散、复杂辐射通道、材料拟合或全谱完备性。

## Legume 与 Ge：APPROXIMATE，严格静态门槛未通过

真实几何为半径1030 nm、周期3296 nm、由近似r/h=.703得到高度1465.149 nm的圆柱阵列。物理层背景及上下包层均为空气。程序核对柱内、柱间、层外介电值；平均薄膜只用作导模展开的参考基底，未替换实际结构。

当前默认材料采用引用来源的Ge substrate表，在68 THz线性插值得 n=3.977072874、表格k=0，冻结Reε=15.81710864。这是明确选择的一种近似；表格k=0既不能证明真实吸收严格为零，也不等于文章的Lorentz参数。Ge film是另一不同数据样本；文章没有说明选了哪一个。

标准Legume先求Hermitian GME实频率，再微扰计算辐射损耗。报告中的复数因此为 `2π(freqs−i freqs_im)`，归一化为ωa/c0；Q仅为微扰辐射Q，未包含材料吸收。它们不是已验证的色散开放复极点。

实际模式筛查纠正了近频误认：gmax=3.1、6个垂向导模时约68.43336 THz的双重属于 **Eg**，不是目标 **A2g**。增加基底后识别到的A2g候选向约69.06 THz移动；例如gmax=8.1/16个垂向模为69.06249 THz，gmax=8.1/12为69.06655 THz，gmax=6.1/16为69.14177 THz。频率仍有空间截断和材料选择影响，不能将其强行平移到68 THz。

Γ点A2g在该无吸收、理想对称近似下受对称性保护，得到的极大辐射Q约1e26–1e29是数值零泄漏的表现，**不代表已测得如此精确的物理Q**，也不能与Fig.4C的单柱Q≈500直接比较。后续需要小非零k点、材料损耗、场身份和截断共同验证。

全路径候选谱、全部GME系数、基底索引和Γ矢量场保存在 `results/legume_reference_*/`；对称性和收敛分析见 `docs/legume_extension.md`。这些结果可支持Legume扩展路线，但不能解除严格静态门槛，因此未继续生成Ge动态本征带。

## 不一致来源与尚未解决的门槛

| 来源 | 证据与当前判断 |
|---|---|
| 几何 | 名义r、a已确认；r/h只给近似值，不能声称未知精确高度已还原 |
| 材料 | **关键缺失**：正式正文/SI未列ε∞、振子数、共振/等离子频率、阻尼和拟合区间；引用来源公开的是非参数n,k表，film/substrate也未明确 |
| 静态模式身份 | 原68.43 THz近频候选属于Eg，作为目标A2g的解释FAILED；场对称性检查避免了错误接入Floquet |
| 辐射边界 | Legume当前为微扰损耗；尚未实现并验证频率相关出射自能或独立PML/DtN Ge后端 |
| 空间截断 | A2g随倒格矢和垂向模截断变化，尚无严格目标复频率/Q的误差界 |
| Floquet耦合 | 均匀和明确Lorentz模型已验证；Ge所需ε∞、色散归一化和开放模矩阵元缺失，不允许用自由g拟合 |
| treams延拓 | 原版0.4.7下半平面晶格和在实轴附近不连续且依赖Ewald参数；作为未经修改的outgoing求极点路线FAILED，原始探针已保存 |
| 作者方法记号 | SI S10阻尼项印为−iγ而非通常−iγω，存在量纲/实响应疑问；只是待澄清的记号或印刷问题，不足以判定作者实际计算有错 |
