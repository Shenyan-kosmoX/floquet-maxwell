# 张量调制如何改变耦合零线

偏振和相对相位怎样改变周期薄膜中 TE–TM 模式的耦合？这个案例使用 Legume 的实际静态模式与电场，计算非对角介电张量的投影，对照 [Jin 等 2025](https://doi.org/10.1038/s41565-025-02003-1) 的官方 **Supplementary Figure 5(a–d)**。

结果展示了从线偏振的轴向零线，到实相位组合的对角相消，再到圆偏振组合移除延伸零线的变化。这个问题适合用来熟悉工具箱中的场投影、复相位和张量组合。

## 模型与输入

| 参数 | 取值 |
| --- | --- |
| 晶格 | 正方晶格，周期 465 nm |
| 薄膜 | AlGaAs，厚度 85 nm |
| 空气孔 | 圆孔，直径 100 nm |
| 包层 | 上方空气，下方 silica |
| 主材料模型 | 无色散折射率：AlGaAs 3.47，silica 1.46 |
| 材料敏感性模型 | AlGaAs 折射率 3.3，重新计算整组静态模式 |
| k 区域 | `kx a/(2π)`、`ky a/(2π)` 均为 0–0.04 |

几何来自正式文章，折射率取自作者预印本 Methods。最终发表版本的完整色散曲线尚未核实，因此本例使用固定折射率比较选择规则。参数出处与材料假设见[来源记录](../../sptc_toolbox/results/jin2025_legume_tensor_20261019/source_contract.json)。

## 从场到耦合

在 AlGaAs 背景区域分别投影单位张量 `yz+zy` 与 `xz+zx`，得到 `Vx` 和 `Vy`：

```text
Vx ∝ ∫ (E_TM,y* E_TE,z + E_TM,z* E_TE,y) dV
Vy ∝ ∫ (E_TM,x* E_TE,z + E_TM,z* E_TE,x) dV
```

模式选取结合频率窗口与电磁场偏振，保留相关 TE 双模中的高频支与目标 TM 支。每个 k 点的两种张量投影使用同一对模式和同一复相位，然后计算 `Vx−Vy` 与 `Vx−iVy`。

Γ 点存在 TE 简并，单一分支的耦合未定义；数据用有效点掩码和 `NaN` 记录这一点。主图采用 25×25 网格，共计算 624 个非 Γ 点。

## 结果与检查

| 组合 | 观察到的特征 | 主图中的指标 |
| --- | --- | --- |
| `Vx` | `kx=0` 的轴向零线 | 轴上残余与离轴参考中位数之比约 `6.41×10⁻¹²` |
| `Vy` | `ky=0` 的轴向零线 | 对应比值约 `3.09×10⁻¹²` |
| `Vx−Vy` | `kx=ky` 的对角相消 | 对角残余比值约 `3.68×10⁻¹¹` |
| `Vx−iVy` | 离 Γ 的统计区域内延伸零线消失 | 621 个统计点均非零，最小幅值约 `0.566 Vref` |

统计点的筛选和各分母见 [plot_metrics.json](../../sptc_toolbox/results/jin2025_legume_tensor_20261019/plot_metrics.json)。圆偏振结果提供有限采样证据，连续区域是否存在其他零点需要更进一步的分析。

验证从几个相互补充的方向展开：

| 检查 | 已有结果及意义 |
| --- | --- |
| 独立实空间积分 | 5 个点最大相对差 `2.85×10⁻¹³`，核对张量分量、符号与尺度 |
| z 积分阶数 16→24 | 耦合对的变化接近浮点精度，支持所用区域积分精度 |
| 面内截止 `gmax` 3.1→4.1 | 共同 9×9 网格的幅值 L2 差约 3.96%–4.11%，零线机制保持 |
| 模式与子空间身份 | 5 个共同 k 点上，TE 双模子空间最小主重叠平方 0.997944，TM 最小 0.999317 |
| 材料折射率 3.47→3.3 | 各面板幅值差约 3.03%–3.28%，零线机制保持 |
| 有限模态动态后端 | 选定 k 点的三模张量输入，保留正负频率后，与独立 Maxwell d/h 时间积分的一周期乘子差约 `3.9×10⁻¹¹` |

动态检查使用专门的控制驱动：频率取当地静态 TM−TE 差，Fourier 张量取 `0.25(Tx−iTy)`。它检验同一有限模态模型的两种求解方法，范围和完整数值见[验证记录](../../sptc_toolbox/results/jin2025_legume_tensor_20261019/validation_checks.json)及[模式身份记录](../../sptc_toolbox/results/jin2025_legume_tensor_20261019/mode_identity_checks.json)。

## 结论与可继续的问题

在所检查的空间截止与材料变化下，实际二维薄膜场支持张量和相对相位引起的选择规则。幅值仍具有约 4% 的空间敏感性；垂直导模基底、完整模态窗口和开放辐射没有在本案例中分别完成完整细化序列。

近 Γ 的相关 TE、TM 频率约为 `fa/c=0.4468` 和 `0.6291`，论文示意值约为 `0.46` 和 `0.617`。绝对频率与亮带宽度的差异继续保留；目前证据主要支持耦合零线及相位关系。

完整 Floquet 拓扑、Chern 数、边缘态、实验散射效率和空间随机张量调制需要各自的模型与验证。希望沿用本案例时，可以从新的偏振组合或晶胞内张量分布开始，再根据所研究的观测量补充相应检查。
